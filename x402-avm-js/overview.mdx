`x402-avm-js` (npm, MIT, version 0.3.0) is a TypeScript library for the client side of the Algorand exact scheme. It decodes a `402` challenge, picks the offer for your wallet's network, builds the payment group, has any wallet sign its part, and encodes the `PAYMENT-SIGNATURE` header. It works on MainNet, TestNet, LocalNet and private networks, with ALGO or any ASA such as USDC.

```bash
npm install x402-avm-js@0.3.0 algosdk
```

## Pay a 402 response

```ts
import { algodClient, decodePaymentRequired, payForRequirement } from 'x402-avm-js';

const algod = algodClient('mainnet'); // or 'testnet', 'localnet', or algodClient(network, url, token)
const res = await fetch(url);
if (res.status === 402) {
  const required = decodePaymentRequired(res.headers.get('PAYMENT-REQUIRED')!);
  const header = await payForRequirement(required, myAddress, algod, (txns, indexes) =>
    wallet.signTransactions(txns, indexes) // Pera, Defly, Lute, KMD, a local key...
  );
  const paid = await fetch(url, { headers: { 'PAYMENT-SIGNATURE': header } });
}
```

`payForRequirement` pays the offer for the network that `algod` is on. A server can offer several networks, for example MainNet USDC and TestNet ALGO. If none of the offers is on the wallet's network, the call throws instead of signing a payment the server cannot use.

No transaction is submitted by the client. The server verifies the signed group, runs the service, and submits the group.

## Runtimes

The library uses only standard web APIs (`Uint8Array`, `TextEncoder`, `TextDecoder`) and imports no Node built-ins, so it runs in browsers, Node.js 18+, web workers and edge runtimes without polyfills. It is published as an ES module.

## Migrating from 0.2

0.3 uses the Algorand CAIP-2 profile for network ids (`algorand:` plus 32 URL-safe base64 characters): `algorand:wGHE2Pwdvd7S12BL5FaOP20EGYesN73k` for MainNet and `algorand:SGO1GKSzyE7IEPItTxCByw9x8FmnrCDe` for TestNet. Legacy 44-character ids are still accepted by `resolveNetwork` and `selectRequirement`, so existing servers keep working.

## Testing the package

```bash
npm test                 # offline tests
PUBLIC_NETS=1 npm test   # also builds payments on TestNet and MainNet and simulates them (no keys, no funds)
LOCALNET=1 npm test      # also settles real payments on a running LocalNet
```
