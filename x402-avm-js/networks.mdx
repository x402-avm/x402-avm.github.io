## CAIP-2 ids

A network id is `algorand:` plus the first 32 characters of the URL-safe base64 genesis hash. `networkFromGenesisHash(hash)` computes it from a base64 string or raw bytes. Legacy 44-character ids are accepted by `resolveNetwork` and `selectRequirement` and converted.

| Function | Input | Output |
|---|---|---|
| `resolveNetwork(name)` | `"mainnet"`, `"testnet"`, `"algorand-mainnet"`, `"algorand-testnet"`, `"algorand"`, a short id or a legacy id | The short id. Throws for anything else, including `"localnet"`. |
| `networkFromGenesisHash(hash)` | Base64 string or `Uint8Array` | The short id |
| `networkFromAlgod(algod)` | An `Algodv2` client | The id of the node's network (async) |
| `algodClient(network, url?, token?)` | `"mainnet"`, `"testnet"`, `"localnet"` or an id with a `url` | An `Algodv2` client |

## Resolve networks

```ts
import { MAINNET, TESTNET, algodClient, networkFromAlgod, resolveNetwork } from 'x402-avm-js';

resolveNetwork('mainnet');  // 'algorand:wGHE2Pwdvd7S12BL5FaOP20EGYesN73k'
resolveNetwork('testnet');  // 'algorand:SGO1GKSzyE7IEPItTxCByw9x8FmnrCDe'

// Ask a live node which network it is on
await networkFromAlgod(algodClient('mainnet'));  // same as MAINNET.caip2
await networkFromAlgod(algodClient('testnet'));  // same as TESTNET.caip2
```

## LocalNet

A LocalNet's genesis hash changes when it is reset, so read its id from the node instead of hard-coding it:

```ts
import { algodClient, networkFromAlgod } from 'x402-avm-js';

const algod = algodClient('localnet');
console.log(await networkFromAlgod(algod));
```

`payForRequirement` does this itself: it reads the network from the algod you pass and pays the matching offer.

## Simulate on public networks

Payment groups can be checked against live TestNet and MainNet state without funds: build them with `payForRequirement` and a signer that returns no signatures, then run algod's simulate endpoint with empty signatures allowed. The full scripts are in the [TestNet](/guides/networks/testnet#check-payments-without-funds) and [MainNet](/guides/networks/mainnet#simulate-on-mainnet) guides.
