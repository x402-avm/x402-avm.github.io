You will build a web page whose premium report unlocks after the visitor pays 4,000 microALGO, signed in the browser with `x402-avm-js`.

## What you will build

- A FastAPI server on port 9232 that serves the page at `/` and protects `GET /api/premium` with the official `x402` middleware (4,000 microALGO).
- A page (`index.html`, `app.js`) bundled with esbuild into `bundle.js`, an ES module the page imports.
- A Node script (`verify.mjs`) that runs the same client functions as the page, for automated checks.

## Prerequisites

- Python 3.10+ and Node.js 20+.
- LocalNet running.
- The files in `localnet/browser_paywall/` of the [examples repository](https://github.com/x402-avm/examples). From the repository root, install the dependencies (`requirements.txt` pins `ai-economy-sdk==0.5.0` and `x402-algorand==0.3.0`; `package.json` has `x402-avm-js` 0.4, `algosdk` and `esbuild`):

```bash
pip install -r requirements.txt
npm install
```

  <Step title="Write the server">
    The server sets up an in-process facilitator and resource server, protects `GET /api/premium`, and serves the static files.

    {/* example: localnet/browser_paywall/server.py */}

    ```python localnet/browser_paywall/server.py expandable
    """Browser paywall server: serves the static page and charges 4,000 microALGO for /api/premium.

        python localnet/browser_paywall/server.py     # http://127.0.0.1:9232
    """
    import sys
    from pathlib import Path

    sys.path.insert(0, str(Path(__file__).resolve().parents[1]))

    import uvicorn
    from fastapi import FastAPI
    from fastapi.staticfiles import StaticFiles
    from x402 import x402Facilitator, x402ResourceServer
    from x402.http.middleware.fastapi import payment_middleware
    from x402_algorand import ServerAvmSigner, caip2_from_genesis_hash
    from x402_algorand.exact import register_exact_avm_facilitator, register_exact_avm_server

    from _localnet import ALGOD, new_funded_account


    def create_app() -> FastAPI:
        network = caip2_from_genesis_hash(ALGOD.suggested_params().gh)
        signer = ServerAvmSigner.from_private_key(new_funded_account()[0], ALGOD)

        facilitator = x402Facilitator()
        register_exact_avm_facilitator(facilitator, signer, network)
        server = x402ResourceServer(facilitator)
        register_exact_avm_server(server)

        routes = {"GET /api/premium": {
            "accepts": [{"scheme": "exact", "pay_to": signer.address,
                         "price": {"amount": "4000", "asset": "0"}, "network": network}],
            "description": "Deep sea exploration premium report",
        }}

        app = FastAPI(title="Browser Paywall")
        app.middleware("http")(payment_middleware(routes, server))

        @app.get("/api/premium")
        def premium():
            return {
                "title": "Deep Sea Hydrothermal Vent Survey",
                "findings": "Dense polymetallic sulfides discovered at depth 2,400m.",
                "status": "unlocked",
            }

        app.mount("/", StaticFiles(directory=Path(__file__).parent, html=True), name="static")
        return app


    if __name__ == "__main__":
        print("Browser paywall on http://127.0.0.1:9232", flush=True)
        uvicorn.run(create_app(), host="127.0.0.1", port=9232, log_level="warning")
    ```

    `app.js` requests the report, and on `402` decodes the challenge, pays it with the visitor's signing function, and retries:

    {/* example: localnet/browser_paywall/app.js */}

    ```javascript localnet/browser_paywall/app.js
    /**
     * Browser paywall client (x402-avm-js): fetch /api/premium, pay the 402 challenge with the
     * caller's wallet signer, retry with PAYMENT-SIGNATURE.
     */
    import algosdk from 'algosdk';
    import { PaymentNotAllowedError, SpendLimitExceededError, decodePaymentRequired, payForRequirement } from 'x402-avm-js';

    // Never pay more than 0.01 ALGO per request, whatever the server asks for.
    const SPEND_CONTROLS = { maxAmount: 10_000n, allowedAssets: ['0'] };

    export async function fetchPremiumContent(
      payerAddress,
      signTxns,
      algodUrl = 'http://localhost:4001',
      algodToken = 'a'.repeat(64),
    ) {
      const first = await fetch('/api/premium');
      if (first.status === 200) return first.json();
      if (first.status !== 402) throw new Error(`Unexpected server response: HTTP ${first.status}`);

      const challenge = decodePaymentRequired(first.headers.get('payment-required'));
      const algod = new algosdk.Algodv2(algodToken, algodUrl, '');

      let signature;
      try {
        signature = await payForRequirement(challenge, payerAddress, algod, signTxns, SPEND_CONTROLS);
      } catch (err) {
        if (err instanceof SpendLimitExceededError || err instanceof PaymentNotAllowedError) {
          throw new Error(`Payment refused by spend controls: ${err.message}`);
        }
        throw err;
      }

      const paid = await fetch('/api/premium', { headers: { 'payment-signature': signature } });
      if (paid.status !== 200) throw new Error(`Payment refused by server: HTTP ${paid.status}`);
      return paid.json();
    }
    ```

  <Step title="Verify from Node">
    `verify.mjs` runs the same `x402-avm-js` calls as `app.js` against the running server, with a LocalNet account instead of a browser wallet.

    {/* example: localnet/browser_paywall/verify.mjs */}

    ```javascript localnet/browser_paywall/verify.mjs
    /**
     * Runs the same x402 client flow as app.js from Node against the paywall on port 9232
     * (start browser_paywall/server.py first):
     *
     *   node localnet/browser_paywall/verify.mjs
     */
    import { decodePaymentRequired, payForRequirement } from 'x402-avm-js';
    import { algod, newFundedAccount, signerFor } from '../_localnet.mjs';

    const URL = 'http://127.0.0.1:9232/api/premium';
    const balance = async (addr) => (await algod.accountInformation(addr).do()).amount;

    const buyer = await newFundedAccount(5);
    const before = await balance(buyer.address);

    const res402 = await fetch(URL);
    if (res402.status !== 402) throw new Error(`Expected 402, got ${res402.status}`);
    const challenge = decodePaymentRequired(res402.headers.get('payment-required'));
    const [req] = challenge.accepts;
    console.log(`402: ${req.amount} units of asset ${req.asset} to ${req.payTo} on ${req.network}`);

    const signature = await payForRequirement(challenge, buyer.address, algod, signerFor(buyer.sk));
    const paid = await fetch(URL, { headers: { 'payment-signature': signature } });
    if (paid.status !== 200) throw new Error(`Expected 200, got ${paid.status}: ${await paid.text()}`);
    console.log('Unlocked:', await paid.json());

    const drop = before - (await balance(buyer.address));
    console.log(`Balance drop: ${drop} microALGO`);
    if (drop !== BigInt(req.amount)) throw new Error(`Expected a drop of ${req.amount}, got ${drop}`);
    console.log('Browser paywall verified.');
    ```

## What happened

1. The page called `fetch("/api/premium")` and received `402` with a `PAYMENT-REQUIRED` header.
2. `decodePaymentRequired()` read the requirement: ALGO (asset `0`), 4,000 microALGO, the LocalNet network id, and the server's fee payer.
3. `payForRequirement()` fetched suggested parameters, built the two-transaction group and asked the signing function to sign the buyer's transaction.
4. The page retried with `PAYMENT-SIGNATURE`.
5. The server verified and settled the payment through its facilitator and returned the report with `200`.
6. The buyer's balance fell by exactly 4,000 microALGO.
