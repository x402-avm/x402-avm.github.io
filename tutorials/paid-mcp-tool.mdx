title: "Build and sell a paid MCP tool"
description: "A FastMCP summarization tool priced by input length, a paying client, and an indexer check of the settled payment."
---

You will build an MCP server with a `summarize(text)` tool that costs 1,000 microALGO per 100 characters of input, with a minimum of 3,000 microALGO, and a client that pays for a call and finds the payment on the indexer.

## Prerequisites

- Python 3.10 or newer, and the examples repository's dependencies: `pip install -r requirements.txt` (pins `ai-economy-sdk==0.4.1`).
- LocalNet running: algod on `http://localhost:4001`, indexer on `http://localhost:8980`, KMD on `http://localhost:4002`.
- The [examples repository](https://github.com/x402-avm/examples); the files are in `localnet/paid_mcp_tool/`.

<Steps>
  <Step title="Write the server">
    The server funds its own account from the LocalNet dispenser, defines the tool, and wraps FastMCP with `PaymentGate` and the pricing function `price_summarize`.

    {/* example: localnet/paid_mcp_tool/server.py */}

    ```python localnet/paid_mcp_tool/server.py expandable
    """Paid MCP tool server tutorial.

    Starts a FastMCP server offering a paid summarize tool, protected by PaymentGate
    on port 9231 with dynamic length-based pricing (1,000 microALGO per 100 characters,
    minimum 3,000 microALGO).

    How to run:
        python server.py

    Expected output:
        Server running on http://127.0.0.1:9231
    """
    import sys
    import uvicorn
    from fastmcp import FastMCP
    from algosdk import account, kmd, transaction
    from algosdk.v2client import algod
    from ai_economy_sdk import DefaultAvmSigner, PaymentGate

    ALGOD = algod.AlgodClient("a" * 64, "http://localhost:4001")


    def dispenser():
        """Retrieve LocalNet dispenser account from KMD."""
        k = kmd.KMDClient("a" * 64, "http://localhost:4002")
        w = next(x for x in k.list_wallets() if x["name"] == "unencrypted-default-wallet")
        h = k.init_wallet_handle(w["id"], "")
        addr = max(k.list_keys(h), key=lambda a: ALGOD.account_info(a)["amount"])
        return addr, k.export_key(h, "", addr)


    def new_funded_account(algos=10):
        """Generate a new account funded from the LocalNet dispenser."""
        sk, addr = account.generate_account()
        d_addr, d_sk = dispenser()
        sp = ALGOD.suggested_params()
        txn = transaction.PaymentTxn(d_addr, sp, addr, algos * 1_000_000)
        ALGOD.send_transaction(txn.sign(d_sk))
        transaction.wait_for_confirmation(ALGOD, txn.get_txid(), 10)
        return sk, addr


    def price_summarize(tool: str, args: dict, sender: str | None = None) -> int:
        """Calculate price based on text length: 1,000 microALGO per 100 chars, min 3,000."""
        if tool == "summarize":
            text = args.get("text", "")
            units = (len(text) + 99) // 100
            return max(3000, units * 1000)
        return 3000


    def create_app():
        # Fund server account on LocalNet
        server_sk, server_addr = new_funded_account(algos=5)
        signer = DefaultAvmSigner(server_sk, algod_client=ALGOD)

        mcp = FastMCP("Summarizer")

        @mcp.tool()
        def summarize(text: str) -> str:
            """Summarize text by extracting the primary sentences."""
            sentences = [s.strip() for s in text.split(".") if s.strip()]
            if len(sentences) <= 2:
                return text.strip()
            return sentences[0] + ". " + sentences[1] + "."

        gate = PaymentGate(
            signer=signer,
            network="localnet",
            pay_to=server_addr,
            asset_id=0,
            prices=price_summarize,
        )
        return gate.wrap(mcp)


    if __name__ == "__main__":
        app = create_app()
        print("Server starting on http://127.0.0.1:9231 ...", flush=True)
        uvicorn.run(app, host="127.0.0.1", port=9231, log_level="warning")
    ```

    <sub>Source: [examples/localnet/paid_mcp_tool/server.py](https://github.com/x402-avm/examples/blob/main/localnet/paid_mcp_tool/server.py)</sub>

    {/* /example */}

    The pricing function runs before the `402` is sent, so the client is quoted the exact price for its input:

    ```python
    def price_summarize(tool: str, args: dict, sender: str | None = None) -> int:
        """Calculate price based on text length: 1,000 microALGO per 100 chars, min 3,000."""
        if tool == "summarize":
            text = args.get("text", "")
            units = (len(text) + 99) // 100
            return max(3000, units * 1000)
        return 3000
    ```

    - Each started block of 100 characters costs 1,000 microALGO.
    - The minimum is 3,000 microALGO, above the 2,000 microALGO the server pays in fees per settled call. A dynamic price at or below 2,000 microALGO would be raised to 2,001 by the gate's [fee floor](/ai-economy-sdk/pricing#the-fee-floor).
  </Step>
  <Step title="Write the client">
    The client funds a buyer, opens a paid session, calls `summarize`, and looks the payment up on the indexer.

    {/* example: localnet/paid_mcp_tool/client.py */}

    ```python localnet/paid_mcp_tool/client.py expandable
    """Paid MCP tool client tutorial.

    Connects to the paid summarize tool on port 9231 via paid_mcp_session, pays the
    x402 payment on Algorand LocalNet, and confirms the transaction via Indexer.

    How to run:
        python client.py

    Expected output:
        Calling summarize tool...
        Result: Algorand is a pure proof-of-stake blockchain. It achieves immediate finality without forks.
        Price paid: 3000 microALGO
        Confirmed TxID: <txid> (confirmed at round <round>)
    """
    import asyncio
    import time
    from algosdk import account, kmd, transaction
    from algosdk.v2client import algod, indexer
    from ai_economy_sdk import paid_mcp_session

    ALGOD = algod.AlgodClient("a" * 64, "http://localhost:4001")
    INDEXER = indexer.IndexerClient("", "http://localhost:8980")


    def dispenser():
        """Retrieve LocalNet dispenser account from KMD."""
        k = kmd.KMDClient("a" * 64, "http://localhost:4002")
        w = next(x for x in k.list_wallets() if x["name"] == "unencrypted-default-wallet")
        h = k.init_wallet_handle(w["id"], "")
        addr = max(k.list_keys(h), key=lambda a: ALGOD.account_info(a)["amount"])
        return addr, k.export_key(h, "", addr)


    def new_funded_account(algos=10):
        """Generate a new account funded from the LocalNet dispenser."""
        sk, addr = account.generate_account()
        d_addr, d_sk = dispenser()
        sp = ALGOD.suggested_params()
        txn = transaction.PaymentTxn(d_addr, sp, addr, algos * 1_000_000)
        ALGOD.send_transaction(txn.sign(d_sk))
        transaction.wait_for_confirmation(ALGOD, txn.get_txid(), 10)
        return sk, addr


    async def main():
        print("Generating funded buyer account on LocalNet...")
        buyer_sk, buyer_addr = new_funded_account(algos=5)

        test_text = (
            "Algorand is a pure proof-of-stake blockchain. "
            "It achieves immediate finality without forks. "
            "Smart contracts run directly on the AVM with predictable micro-cent fees."
        )

        start_round = ALGOD.status()["last-round"]

        print("Opening paid MCP session to http://127.0.0.1:9231/sse ...")
        async with paid_mcp_session(
            sse_url="http://127.0.0.1:9231/sse",
            private_key=buyer_sk,
            network="localnet",
            algod_url="http://localhost:4001",
            algod_token="a" * 64,
        ) as session:
            print("Calling summarize tool...")
            res = await session.call_tool("summarize", {"text": test_text})

            summary_text = ""
            for content in res.content:
                if hasattr(content, "text"):
                    summary_text += content.text
                elif isinstance(content, dict) and "text" in content:
                    summary_text += content["text"]
                else:
                    summary_text += str(content)

            print(f"Result: {summary_text.strip()}")

        # Look up payment transaction on Indexer by buyer address
        # Give indexer up to 5 seconds to ingest
        found_txn = None
        for _ in range(10):
            time.sleep(0.5)
            resp = INDEXER.search_transactions(address=buyer_addr, txn_type="pay", min_round=start_round)
            txns = resp.get("transactions", [])
            if txns:
                found_txn = txns[0]
                break

        if not found_txn:
            raise RuntimeError(f"Payment transaction for {buyer_addr} not found in indexer")

        txid = found_txn["id"]
        price = found_txn["payment-transaction"]["amount"]
        confirmed_round = found_txn.get("confirmed-round")

        print(f"Price paid: {price} microALGO")
        print(f"Confirmed TxID: {txid} (confirmed at round {confirmed_round})")


    if __name__ == "__main__":
        asyncio.run(main())
    ```

## What happened on chain

1. The client called `summarize` over MCP.
2. The gate priced the 153-character input at 3,000 microALGO (two blocks of 100 characters is 2,000, below the minimum) and answered `402`.
3. The client built the two-transaction group: the server's fee payer transaction with a 2,000 microALGO fee, and the buyer's 3,000 microALGO payment with fee 0.
4. The server verified the payment, ran the tool, submitted the group and returned the summary.
5. The client queried the indexer for its payment and found it in a confirmed round.
