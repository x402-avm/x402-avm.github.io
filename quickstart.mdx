---
title: "Quickstart"
description: "Run a paid MCP tool on Algorand LocalNet and pay for it from Python and from JavaScript."
---

In this quickstart you start a local Algorand network, run an MCP server whose `echo` tool costs 5,000 microALGO per call, and pay for calls from a Python client. A last step pays an x402 HTTP endpoint from JavaScript with `x402-avm-js`.

Everything runs on LocalNet, so no real funds are involved. The scripts come from the [examples repository](https://github.com/x402-avm/examples) and fund their own accounts from the LocalNet dispenser.

## Prerequisites

- Python 3.10 or newer
- Node.js 20 or newer (for the JavaScript step)
- [AlgoKit](https://github.com/algorandfoundation/algokit-cli) and Docker, to run LocalNet

<Steps>
  <Step title="Start LocalNet">
    ```bash
    algokit localnet start
    ```

    This starts algod on `http://localhost:4001`, the indexer on `http://localhost:8980` and KMD on `http://localhost:4002`. The examples fund new accounts from KMD's `unencrypted-default-wallet`.
  </Step>
  <Step title="Get the examples and install the SDK">
    ```bash
    git clone https://github.com/x402-avm/examples.git
    cd examples
    python -m venv .venv && source .venv/bin/activate
    pip install -r requirements.txt
    npm install
    ```

    `requirements.txt` pins `ai-economy-sdk==0.5.0` and `x402-algorand==0.3.0` (which bring the official `x402` package, FastMCP and `py-algorand-sdk`), plus FastAPI, Flask and uvicorn for the HTTP examples. `npm install` installs `x402-avm-js` and `algosdk` for the JavaScript examples.
  </Step>
  <Step title="Run the paid MCP server">
    The server funds a fresh account with 10 ALGO, wraps a FastMCP server with `PaymentGate`, prices `echo` at 5,000 microALGO, and serves the MCP Streamable HTTP transport (`POST /mcp`).

    {/* example: localnet/quickstart_server.py */}

    ```python localnet/quickstart_server.py expandable
    """FastMCP server payment-gated with ai-economy-sdk on Algorand LocalNet.

    Runs a FastMCP server with a single paid 'echo' tool priced at 5,000 microALGO.
    Funds a server account from LocalNet dispenser and serves Streamable HTTP (/mcp) on port 9201.

    How to run:
        python localnet/quickstart_server.py

    What it prints:
        pay_to: <44-character Algorand address>
    """
    import sys
    from pathlib import Path

    # Add current directory to path so _localnet can be imported
    sys.path.insert(0, str(Path(__file__).resolve().parent))

    import uvicorn
    from fastmcp import FastMCP
    from ai_economy_sdk import DefaultAvmSigner, PaymentGate
    from _localnet import ALGOD, new_funded_account

    SERVER_PORT = 9201
    TOOL_PRICE_MICROALGO = 5000


    def main() -> None:
        server_sk, server_addr = new_funded_account(algos=10)
        print(f"pay_to: {server_addr}", flush=True)

        mcp = FastMCP("QuickstartServer")

        @mcp.tool()
        def echo(text: str) -> str:
            """Echo back input text."""
            return f"echo: {text}"

        gate = PaymentGate(
            signer=DefaultAvmSigner(server_sk, algod_client=ALGOD),
            network="localnet",
            pay_to=server_addr,
            asset_id=0,
            prices={"echo": TOOL_PRICE_MICROALGO},
        )

        app = gate.wrap(mcp, transport="streamable-http")
        uvicorn.run(app, host="127.0.0.1", port=SERVER_PORT, log_level="warning")


    if __name__ == "__main__":
        main()
    ```

    <sub>Source: [examples/localnet/quickstart_server.py](https://github.com/x402-avm/examples/blob/main/localnet/quickstart_server.py)</sub>

    {/* /example */}

    ```bash
    python localnet/quickstart_server.py
    ```

    It prints the address that receives payments and serves `http://127.0.0.1:9201/mcp`:

    ```text
    pay_to: GL4IOGTXMILQYI2UOSYORNW4LHB4SULTDRYCA4AMFQUGKTEYN3ZUDQG6XE
    ```

    The address is different on every run.

    <Note>
      `gate.wrap(mcp, transport="streamable-http")` is the recommended transport. Pass `transport="sse"` only for MCP clients that still speak the legacy HTTP+SSE transport (`GET /sse` and `POST /messages/`). Calling `wrap(mcp)` without `transport=` still serves SSE, as 0.4 did, and emits a `FutureWarning`: the default will change to Streamable HTTP in a later release. See [Transports](/ai-economy-sdk/server#transports).
    </Note>
  </Step>
  <Step title="Call the tool from Python">
    In a second terminal, run the client. It funds a buyer with 5 ALGO, opens a paid session, calls `echo`, and measures the buyer's balance before and after.

    {/* example: localnet/quickstart_client.py */}

    ```python localnet/quickstart_client.py
    """Paid MCP client session using ai-economy-sdk on Algorand LocalNet.

    Funds a fresh buyer account via the LocalNet dispenser, establishes a paid MCP
    session to http://127.0.0.1:9201/mcp, calls the 'echo' tool, and verifies the on-chain
    charge.

    How to run:
        1. Start quickstart_server.py in the background
        2. python localnet/quickstart_client.py

    What it prints:
        Result: echo: hello world
        Balance drop: 5000 microALGO
    """
    import asyncio
    import sys
    from pathlib import Path

    sys.path.insert(0, str(Path(__file__).resolve().parent))

    from ai_economy_sdk import AIEconomyError, paid_mcp_session
    from _localnet import ALGOD, new_funded_account

    SERVER_URL = "http://127.0.0.1:9201/mcp"


    async def main() -> None:
        buyer_sk, buyer_addr = new_funded_account(algos=5)
        before_balance = ALGOD.account_info(buyer_addr)["amount"]

        try:
            async with paid_mcp_session(SERVER_URL, buyer_sk, "localnet") as session:
                result = await session.call_tool("echo", {"text": "hello world"})
                print(f"Result: {result.content[0].text}")
        except AIEconomyError as err:  # payment refused, settlement failed, bad config ...
            raise SystemExit(f"Paid call failed: {err}")

        after_balance = ALGOD.account_info(buyer_addr)["amount"]
        drop = before_balance - after_balance
        print(f"Balance drop: {drop} microALGO")


    if __name__ == "__main__":
        asyncio.run(main())
    ```

    The buyer paid exactly the price. The server's fee payer paid the 2,000 microALGO of network fees.
  </Step>
  <Step title="Pay from JavaScript">
    `x402-avm-js` pays any x402 endpoint that uses the Algorand exact scheme. This example pays a small FastAPI paywall (5,000 microALGO on `GET /paid`, port 9221) built with `x402-algorand`. Start the server, then run the client:

    ```bash
    python localnet/server_for_js.py
    ```

    ```bash
    node localnet/js_pay.mjs
    ```

    {/* example: localnet/js_pay.mjs */}

    ```javascript localnet/js_pay.mjs expandable
    /**
     * Pay an x402 paywall from JavaScript on LocalNet (start server_for_js.py first, port 9221).
     *
     *   node localnet/js_pay.mjs
     *
     * Fetch -> 402 -> decodePaymentRequired -> payForRequirement (with explicit spend controls)
     * -> retry with PAYMENT-SIGNATURE -> check the exact 5000 microALGO balance drop.
     */
    import { SpendLimitExceededError, X402AvmError, decodePaymentRequired, payForRequirement } from 'x402-avm-js';
    import { algod, newFundedAccount, signerFor } from './_localnet.mjs';

    const URL = 'http://127.0.0.1:9221/paid';
    const balance = async (addr) => (await algod.accountInformation(addr).do()).amount;

    const buyer = await newFundedAccount();
    const before = await balance(buyer.address);

    const res402 = await fetch(URL);
    if (res402.status !== 402) throw new Error(`Expected 402, got ${res402.status}`);
    const challenge = decodePaymentRequired(res402.headers.get('payment-required'));
    const [req] = challenge.accepts;
    console.log(`Server asks ${req.amount} units of asset ${req.asset} -> ${req.payTo}`);

    // Spend controls are checked before anything is signed. The default cap is 1,000,000 base units;
    // here we tighten it and pin the asset, network and recipient.
    const controls = {
      maxAmount: 10_000n,
      allowedAssets: ['0'],
      allowedNetworks: [req.network],
      allowedPayTo: [req.payTo],
    };

    try {
      const signature = await payForRequirement(challenge, buyer.address, algod, signerFor(buyer.sk), controls);
      const paid = await fetch(URL, { headers: { 'payment-signature': signature } });
      console.log(`Paid response: ${paid.status}`, await paid.json());
    } catch (err) {
      if (err instanceof SpendLimitExceededError) throw new Error(`Refused to overpay: ${err.message}`);
      if (err instanceof X402AvmError) throw new Error(`x402 error ${err.code}: ${err.message}`);
      throw err;
    }

    const drop = before - (await balance(buyer.address));
    console.log(`Balance drop: ${drop} microALGO`);
    if (drop !== 5000n) throw new Error(`Expected a drop of 5000 microALGO, got ${drop}`);

    // A 50,000 microALGO demand would exceed the 10,000 cap and is refused without signing.
    const greedy = { ...challenge, accepts: [{ ...req, amount: '50000' }] };
    await payForRequirement(greedy, buyer.address, algod, signerFor(buyer.sk), controls).then(
      () => { throw new Error('Spend cap did not trigger'); },
      (err) => console.log(`Over-cap request rejected: ${err.constructor.name}`),
    );
    ```

    <sub>Source: [examples/localnet/js_pay.mjs](https://github.com/x402-avm/examples/blob/main/localnet/js_pay.mjs)</sub>

    {/* /example */}

    ```text
    Server asks 5000 units of asset 0 -> UR633JM3BS4KZMBELB7COIFAN65JOL5JLSDMHKT34FX4NXHJATFOFTQRWA
    Paid response: 200 {
      status: 'ok',
      data: 'Access granted to premium resource',
      txid: 'B3UQGJQZVSHVNNTS6TZ7H4ONG6DRJVTBBRI2V6CDTM45MLFBYLZA',
      payer: 'PVGZFLS3MLQRRH2QJMRQUMH75ZOQQYNSPKFKXFN2URPIJ4MSTFBAZI6WB4'
    }
    Balance drop: 5000 microALGO
    Over-cap request rejected: SpendLimitExceededError
    ```

    The last line is the spend controls at work. `payForRequirement` checks every offer against them before anything is signed: by default it refuses any payment above 1,000,000 base units (1 ALGO or 1 USDC), and here the script tightens the cap to 10,000 and pins the asset, network and recipient. A server that asks for more gets a `SpendLimitExceededError`, and the wallet is never asked to sign. See [Guardrails](/agents/guardrails#javascript-clients).

    <Note>
      `x402-avm-js` builds and signs payments; it does not include an MCP client transport. To call paid MCP tools from code, use `paid_mcp_session` from Python, or decode the `402` returned by a tool call yourself as shown on [Discovering prices](/agents/discovering-prices).
    </Note>
  </Step>
</Steps>

## What happened

1. The client called `echo` with `{"text": "hello world"}`.
2. `PaymentGate` answered with HTTP `402` and a `PAYMENT-REQUIRED` header: scheme `exact`, the LocalNet CAIP-2 network id, asset `0` (ALGO), amount `5000`, the server's `payTo` address and its fee payer.
3. The client built a two-transaction atomic group:
   - Transaction 0: the server's fee payer pays itself 0 ALGO with a 2,000 microALGO fee that covers both transactions.
   - Transaction 1: the buyer pays 5,000 microALGO to `payTo` with a fee of 0. The client signs only this one.
4. The client retried the call with the signed group in the `PAYMENT-SIGNATURE` header.
5. The server verified the group (including a simulation on algod), ran the tool, and because it succeeded, signed the fee payer transaction and submitted the group.
