In five minutes you will have an MCP server whose `echo` tool costs 5,000 microALGO per call, a Python client that pays for it, and a JavaScript client that pays an HTTP endpoint. Everything runs on LocalNet, a private Algorand network on your machine, so no real money is involved.

## Prerequisites

- Python 3.10 or newer
- Node.js 20 or newer (for the JavaScript step)
- [AlgoKit](https://github.com/algorandfoundation/algokit-cli) and Docker, to run LocalNet

<Steps>
  <Step title="Start LocalNet">
    ```bash
    algokit localnet start
    ```

    algod listens on `http://localhost:4001` and the indexer on `http://localhost:8980`. The examples fund new accounts from LocalNet's built-in dispenser, so you need no keys.
  </Step>
  <Step title="Get the examples">
    ```bash
    git clone https://github.com/x402-avm/examples.git
    cd examples
    python -m venv .venv && source .venv/bin/activate
    pip install -r requirements.txt
    npm install
    ```

    This installs `ai-economy-sdk` 0.5.1, `x402-algorand` 0.3.0 and `x402-avm-js` 0.4.1 with their dependencies.
  </Step>
  <Step title="Run the paid MCP server">
    {/* example: localnet/quickstart_server.py */}

    ```python localnet/quickstart_server.py expandable
    """FastMCP server payment-gated with ai-economy-sdk on Algorand LocalNet.

    Runs a FastMCP server with a single paid 'echo' tool priced at 5,000 microALGO.
    Funds a server account from LocalNet dispenser and serves Streamable HTTP (/mcp) on port 9201.

    How to run:
        python localnet/quickstart_server.py

    What it prints:
        pay_to: <44-character Algorand address>
    """
    import sys
    from pathlib import Path

    # Add current directory to path so _localnet can be imported
    sys.path.insert(0, str(Path(__file__).resolve().parent))

    import uvicorn
    from fastmcp import FastMCP
    from ai_economy_sdk import DefaultAvmSigner, PaymentGate
    from _localnet import ALGOD, new_funded_account

    SERVER_PORT = 9201
    TOOL_PRICE_MICROALGO = 5000


    def main() -> None:
        server_sk, server_addr = new_funded_account(algos=10)
        print(f"pay_to: {server_addr}", flush=True)

        mcp = FastMCP("QuickstartServer")

        @mcp.tool()
        def echo(text: str) -> str:
            """Echo back input text."""
            return f"echo: {text}"

        gate = PaymentGate(
            signer=DefaultAvmSigner(server_sk, algod_client=ALGOD),
            network="localnet",
            pay_to=server_addr,
            asset_id=0,
            prices={"echo": TOOL_PRICE_MICROALGO},
        )

        app = gate.wrap(mcp, transport="streamable-http")
        uvicorn.run(app, host="127.0.0.1", port=SERVER_PORT, log_level="warning")


    if __name__ == "__main__":
        main()
    ```

  <Step title="Pay for a call from Python">
    In a second terminal:

    {/* example: localnet/quickstart_client.py */}

    ```python localnet/quickstart_client.py
    """Paid MCP client session using ai-economy-sdk on Algorand LocalNet.

    Funds a fresh buyer account via the LocalNet dispenser, establishes a paid MCP
    session to http://127.0.0.1:9201/mcp, calls the 'echo' tool, and verifies the on-chain
    charge.

    How to run:
        1. Start quickstart_server.py in the background
        2. python localnet/quickstart_client.py

    What it prints:
        Result: echo: hello world
        Balance drop: 5000 microALGO
    """
    import asyncio
    import sys
    from pathlib import Path

    sys.path.insert(0, str(Path(__file__).resolve().parent))

    from ai_economy_sdk import AIEconomyError, paid_mcp_session
    from _localnet import ALGOD, new_funded_account

    SERVER_URL = "http://127.0.0.1:9201/mcp"


    async def main() -> None:
        buyer_sk, buyer_addr = new_funded_account(algos=5)
        before_balance = ALGOD.account_info(buyer_addr)["amount"]

        try:
            async with paid_mcp_session(SERVER_URL, buyer_sk, "localnet") as session:
                result = await session.call_tool("echo", {"text": "hello world"})
                print(f"Result: {result.content[0].text}")
        except AIEconomyError as err:  # spend controls refused the price (SpendLimitExceededError, 0.5.1+), settlement failed, bad config ...
            raise SystemExit(f"Paid call failed: {err}")

        after_balance = ALGOD.account_info(buyer_addr)["amount"]
        drop = before_balance - after_balance
        print(f"Balance drop: {drop} microALGO")


    if __name__ == "__main__":
        asyncio.run(main())
    ```

  <Step title="Pay from JavaScript">
    `x402-avm-js` pays any x402 endpoint on Algorand. Start a small FastAPI paywall (`GET /paid` on port 9221, 5,000 microALGO), then run the client:

    ```bash
    python localnet/server_for_js.py
    ```

    ```bash
    node localnet/js_pay.mjs
    ```

    {/* example: localnet/js_pay.mjs */}

    ```javascript localnet/js_pay.mjs expandable
    /**
     * Pay an x402 paywall from JavaScript on LocalNet (start server_for_js.py first, port 9221).
     *
     *   node localnet/js_pay.mjs
     *
     * Fetch -> 402 -> decodePaymentRequired -> payForRequirement (with explicit spend controls)
     * -> retry with PAYMENT-SIGNATURE -> check the exact 5000 microALGO balance drop.
     */
    import { SpendLimitExceededError, X402AvmError, decodePaymentRequired, payForRequirement } from 'x402-avm-js';
    import { algod, newFundedAccount, signerFor } from './_localnet.mjs';

    const URL = 'http://127.0.0.1:9221/paid';
    const balance = async (addr) => (await algod.accountInformation(addr).do()).amount;

    const buyer = await newFundedAccount();
    const before = await balance(buyer.address);

    const res402 = await fetch(URL);
    if (res402.status !== 402) throw new Error(`Expected 402, got ${res402.status}`);
    const challenge = decodePaymentRequired(res402.headers.get('payment-required'));
    const [req] = challenge.accepts;
    console.log(`Server asks ${req.amount} units of asset ${req.asset} -> ${req.payTo}`);

    // Spend controls are checked before anything is signed. The default cap is 1,000,000 base units;
    // here we tighten it and pin the asset, network and recipient.
    const controls = {
      maxAmount: 10_000n,
      allowedAssets: ['0'],
      allowedNetworks: [req.network],
      allowedPayTo: [req.payTo],
    };

    try {
      const signature = await payForRequirement(challenge, buyer.address, algod, signerFor(buyer.sk), controls);
      const paid = await fetch(URL, { headers: { 'payment-signature': signature } });
      console.log(`Paid response: ${paid.status}`, await paid.json());
    } catch (err) {
      if (err instanceof SpendLimitExceededError) throw new Error(`Refused to overpay: ${err.message}`);
      if (err instanceof X402AvmError) throw new Error(`x402 error ${err.code}: ${err.message}`);
      throw err;
    }

    const drop = before - (await balance(buyer.address));
    console.log(`Balance drop: ${drop} microALGO`);
    if (drop !== 5000n) throw new Error(`Expected a drop of 5000 microALGO, got ${drop}`);

    // A 50,000 microALGO demand would exceed the 10,000 cap and is refused without signing.
    const greedy = { ...challenge, accepts: [{ ...req, amount: '50000' }] };
    await payForRequirement(greedy, buyer.address, algod, signerFor(buyer.sk), controls).then(
      () => { throw new Error('Spend cap did not trigger'); },
      (err) => console.log(`Over-cap request rejected: ${err.constructor.name}`),
    );
    ```

## What just happened

Your client called `echo`, the server answered `402 Payment Required` with a price, the client signed a payment for exactly that price and retried, and the server ran the tool and then settled the payment on chain. [How it works](/how-it-works) walks through each step.
