An AI agent that finds a useful tool can't use it if the tool wants a sign-up form, a credit card and an API key. And a tool worth a tenth of a cent per call can't be sold on card rails at all.

x402-avm fixes both. Your server answers a call with **HTTP 402 Payment Required** and a price. The caller's wallet pays it on Algorand and retries, and the call goes through. There are no accounts, no keys to issue and no invoices. Payment and result come back in the same request, in about three seconds.

## Why it works for both sides

**For the seller,** a price is one line of code: `prices={"summarize": 5000}`. Payments land directly in your Algorand account, in ALGO or USDC, with nothing in between taking a cut. The payment is checked before your tool runs.

**For the buyer,** you pay only when the call succeeds. The server checks the payment, runs the tool, and submits the payment to the chain only if the tool returned a result. If the tool fails, nothing is charged. The seller pays the network fee, so the buyer's balance goes down by exactly the price shown.

**For whoever owns the agent,** spend limits are checked before anything is signed: a maximum per call, and which assets, networks and recipients may be paid. Both clients apply a limit even if you set none, refusing anything over 1 ALGO or 1 USDC per call until you raise it.

## How it looks in code

<CodeGroup>
```python Sell (server.py)
from fastmcp import FastMCP
from ai_economy_sdk import PaymentGate

mcp = FastMCP("Summarizer")

@mcp.tool()
def summarize(text: str) -> str:
    return text[:200]

gate = PaymentGate(
    signer=signer,                  # your server's key; it pays the network fee
    network="testnet",
    pay_to=my_address,              # where the money goes
    prices={"summarize": 5000},     # 0.005 ALGO per call
)
app = gate.wrap(mcp, transport="streamable-http")
```

```python Buy (agent.py)
from ai_economy_sdk import paid_mcp_session

async with paid_mcp_session(url, wallet_key, "testnet") as session:
    result = await session.call_tool("summarize", {"text": article})
```

```ts Buy (browser)
import { algodClient, decodePaymentRequired, payForRequirement } from 'x402-avm-js';

const res = await fetch(url);
if (res.status === 402) {
  const required = decodePaymentRequired(res.headers.get('PAYMENT-REQUIRED')!);
  const payment = await payForRequirement(required, address, algodClient('testnet'),
    (txns, idx) => wallet.signTransactions(txns, idx));
  await fetch(url, { headers: { 'PAYMENT-SIGNATURE': payment } });
}
```
</CodeGroup>

## What's in the box

x402-avm is three open-source packages. Most projects need only one.

| Package | Install | Use it to |
|---|---|---|
| [`ai-economy-sdk`](/build/sell-mcp-tools) | `pip install ai-economy-sdk` | Sell MCP tools, and pay for them from Python and agents |
| [`x402-algorand`](/build/paywall-http-api) | `pip install x402-algorand` | Add Algorand to the official [x402](https://www.x402.org) SDK, for HTTP APIs and facilitators |
| [`x402-avm-js`](/build/pay-from-browser) | `npm install x402-avm-js algosdk` | Pay from a browser wallet or Node.js |

All three follow the open x402 standard and the official [Algorand `exact` scheme](/reference/protocol/avm-exact-scheme), so they work with any other x402 software on Algorand.
