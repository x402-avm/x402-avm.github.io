<Update label="2026-11-18" description="ai-economy-sdk 0.4.0, x402-algorand 0.2.0, x402-avm-js 0.3.0, and earlier 0.2/0.3 releases" tags={["Python", "JavaScript", "Licensing"]}>
  ## x402-algorand 0.2.0

  **Changed**

  - x402-algorand is now a plugin for the official `x402` Python SDK (`x402>=2.28,<3`, github.com/x402-foundation/x402). It ships only the Algorand exact scheme, under the import name `x402_algorand` (was `x402.mechanisms.avm` inside a fork of the whole SDK).
  - Network ids follow the Algorand CAIP-2 profile: `algorand:` plus the first 32 characters of the URL-safe base64 genesis hash (MainNet `algorand:wGHE2Pwdvd7S12BL5FaOP20EGYesN73k`, TestNet `algorand:SGO1GKSzyE7IEPItTxCByw9x8FmnrCDe`). Legacy long ids are accepted and converted.
  - The facilitator checks the network by the id derived from each transaction's genesis hash, so LocalNet and private networks need no registry entry.

  **Added**

  - `caip2_from_genesis_hash`, `register_network` and `get_genesis_hash` helpers.
  - The client scheme implements `find_default_asset`, so the official `x402Client` spend controls pay ALGO and USDC by default (capped at 1,000,000 base units per payment); other assets are allowed with `x402Client.set_spend_controls(...)`.
  - The client refuses to build a payment when its algod is on a different network than the requirement.

  **Removed**

  - The bundled copy of the x402 core SDK (`x402/`); install the official `x402` package instead.

  ## ai-economy-sdk 0.4.0

  **Added**

  - Integration with the official `x402>=2.28` framework and the `x402-algorand>=0.2.0` plugin.
  - `spend_controls` parameter of `paid_mcp_session` (`dict | Literal[False] | None = None`), to enforce per-payment caps or allow custom ASAs before signing.
  - NumPy-style docstrings across the public API (`PaymentGate`, `paid_mcp_session`, `ChainReader`, `DefaultAvmSigner`).

  **Changed**

  - Monkeypatches removed in favour of the native `find_default_asset` and spend control filtering provided by `x402-algorand`.
  - Network ids follow the Algorand CAIP-2 profile (first 32 characters of the URL-safe base64 genesis hash).

  ## x402-avm-js 0.3.0

  **Added**

  - CAIP-2 short network ids (`algorand:` plus 32 characters), with fallback for legacy 44-character ids.
  - Compatibility with the official `x402` 2.28 protocol and the `x402_algorand` plugin.
  - Native ALGO (asset 0) and ASAs, including Circle USDC.
  - Fee sponsorship through `feePayer` two-transaction atomic groups.
  - Identity proofs with `buildIdentityTxn` and `encodeIdentityHeader` (`X-Identity-Txn`).
  - A self-contained test suite that funds LocalNet accounts from the KMD dispenser and creates its own test ASAs.

  Migration notes: [x402-algorand from 0.1.x](/x402-algorand/overview#migrating-from-0-1-x), [ai-economy-sdk from 0.3](/ai-economy-sdk/overview#migrating-from-0-3), [x402-avm-js from 0.2](/x402-avm-js/overview#migrating-from-0-2).

  ## ai-economy-sdk 0.3.1

  - Added vendor passes: `ChainReader.active_passes()`, `ChainReader.has_pass()` and `PaymentGate(pass_scopes=..., pass_days=...)`.
  - The MIT `LICENSE` file ships in the package.
  - Requires `x402-algorand>=0.1.4`.

  ## ai-economy-sdk 0.3.0

  - Multi-network resolution: `PaymentGate`, `AIEconomySDK` and `paid_mcp_session` accept `"mainnet"`, `"testnet"`, `"localnet"` and CAIP-2 ids.
  - New network utilities: `resolve_network`, `endpoints_for`, `is_public` and `usdc_asset_id`.
  - Identity proofs for browser wallets: `make_identity_txn`, `sign_identity_txn` and `verify_identity_txn`, producing zero-fee `X-Identity-Txn` proofs.
  - Subscription issuer enforcement: `PaymentGate(subscription_issuer=...)` and `has_active_subscription(issuer=...)`.
  - `paid_mcp_session` resolves algod endpoints from the network (AlgoNode for MainNet and TestNet).
  - The 2,000 microALGO fee floor applies only to native ALGO prices.

  ## x402-algorand 0.1.4

  - Licensed Apache-2.0 like the projects it derives from (GoPlausible/x402-avm, coinbase/x402). Ships `LICENSE` and `NOTICE`, and each file changed from x402-avm 2.0.2 says so. Releases 0.1.0 to 0.1.3 were labelled MIT by mistake.

  ## x402-algorand 0.1.3

  - Package metadata update (README as the PyPI description). Network ids were still the long form `algorand:<full genesis hash>`.

  ## x402-avm-js 0.2.1

  - The MIT `LICENSE` file is included in the published npm package.

  ## x402-avm-js 0.2.0

  - No Node `Buffer` dependency: runs in browsers, workers and edge runtimes without polyfills.
  - Network presets and helpers: `MAINNET`, `TESTNET`, `LOCALNET_ENDPOINTS`, `resolveNetwork`, `networkFromAlgod`, `networkFromGenesisHash`, `algodClient` and `selectRequirement`.
  - `payForRequirement` checks that the algod's network matches the server's offers and throws when none matches.
  - Read-only `PUBLIC_NETS=1` tests on MainNet and TestNet.
  - Published package manifest with an `exports` map, types, and build and tests in `prepublishOnly`.
</Update>

<Update label="2026-11-17" description="ai-economy-sdk 0.2.0, x402-avm-js 0.1.0" tags={["Python", "JavaScript"]}>
  ## ai-economy-sdk 0.2.0

  - Settle-on-success: `PaymentGate` verifies payments before the tool runs and settles only after the tool succeeds.
  - Replay protection: `ReplayStore`, in memory or SQLite in WAL mode for several processes.
  - Fee floor: ALGO prices at or below 2,000 microALGO are rejected at start-up unless `allow_loss=True`.
  - Caller identity: `sign_identity` and `verify_identity`.

  ## x402-avm-js 0.1.0

  - First implementation of the Algorand exact-scheme client: parse `PAYMENT-REQUIRED`, build the transaction group, sign through a wallet callback and encode `PAYMENT-SIGNATURE`.
</Update>
