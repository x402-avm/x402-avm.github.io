Every page of this site is available as plain Markdown, and the whole site is available as one text file. Give these to a coding assistant, an agent or a chat model so it answers from the current documentation.

## Files for models

| URL | Contents | Use it when |
|---|---|---|
| [`/llms.txt`](https://x402-avm.github.io/llms.txt) | An index of every page: title, one-line description, link to its Markdown version, grouped as in the navigation. | The tool can follow links and fetch only what it needs. |
| [`/llms-full.txt`](https://x402-avm.github.io/llms-full.txt) | The full text of every page in navigation order, as Markdown. | You want to paste or attach everything at once. |
| `/<page>.md` | One page as Markdown, for example [`/quickstart.md`](https://x402-avm.github.io/quickstart.md) or [`/reference/python/ai-economy-sdk/paid-mcp-session.md`](https://x402-avm.github.io/reference/python/ai-economy-sdk/paid-mcp-session.md). | The tool needs one topic. |

The files follow the [llms.txt convention](https://llmstxt.org). They are rebuilt from the page sources every time the site is deployed, so they match the HTML pages.

## Copy a page

Each page has a menu next to its title with:

- **Copy page**: copies the page as Markdown, ready to paste into a chat.
- **View as Markdown**: opens the page's `.md` version.
- **Open in ChatGPT** and **Open in Claude**: start a conversation about the page.

## Where the reference comes from

The API reference pages are generated from the docstrings of the Python packages and the TSDoc of `x402-avm-js`, so a model reading them sees the same signatures and parameter descriptions as the source code. Each reference page links to the exact source line.

## Repository guidance for coding agents

Each repository of the organization has an `AGENTS.md` file with build, test and contribution rules for agents working on that repository. See [AGENTS.md files](/agents/agents-md).
