[AGENTS.md](https://agents.md) is a plain Markdown file at the root of a repository that tells coding agents how to work on it: how to set up the environment, run the tests, follow the conventions, and what never to do. It complements the README, which is written for people.

Every repository in the [x402-avm organization](https://github.com/x402-avm) has one at its root. An agent working on a repository should read that repository's `AGENTS.md` first; it takes precedence over the organization-wide file.

## What the hub file covers

The hub's `AGENTS.md` is the entry point for an agent that does not yet know which repository it needs. It maps tasks to repositories (sell MCP tools: `ai-economy-sdk`; add Algorand to an x402 SDK server or client: `x402-algorand`; pay from a browser or Node: `x402-avm-js`) and sets rules that apply everywhere.

### Test modes

All packages use the same three test tiers:

| Mode | Python | JavaScript | Needs |
|---|---|---|---|
| Offline | `python -m pytest tests -q` | `npm test` | Nothing |
| `LOCALNET=1` | `LOCALNET=1 python -m pytest tests -q` | `LOCALNET=1 npm test` | AlgoKit LocalNet running |
| `PUBLIC_NETS=1` | `PUBLIC_NETS=1 python -m pytest tests -q -m public` | `PUBLIC_NETS=1 npm test` | Internet access; read-only simulation, no keys or funds |

Each package's README and `AGENTS.md` state exactly which modes it supports.

### Conventions every agent follows

- Use CAIP-2 network ids (`algorand:wGHE2Pwdvd7S12BL5FaOP20EGYesN73k`, `algorand:SGO1GKSzyE7IEPItTxCByw9x8FmnrCDe`); do not hand-write the 44-character form in new code.
- Amounts are integers in base units; USDC has 6 decimals (MainNet 31566704, TestNet 10458941).
- Never commit private keys, mnemonics or tokens; read them from the environment.
- Never send a MainNet transaction from a test. Settle on LocalNet; use `PUBLIC_NETS=1` simulation for public networks.
- Tests must not depend on local paths or pre-existing accounts; LocalNet tests fund fresh accounts from the KMD dispenser.
- Documentation uses plain, precise language, without marketing terms or emojis.

## This site's file

The documentation repository's `AGENTS.md` explains how to edit pages, preview the site, check links, regenerate the API reference from the package sources, and refresh the inlined examples. In short:

```bash
npx -y mint@4.3.63 dev            # preview at http://localhost:3000
npx -y mint@4.3.63 broken-links   # must report no broken links
python scripts/gen_python_reference.py --ai-economy-sdk ../ai-economy-sdk --x402-algorand ../x402-algorand
python scripts/gen_js_reference.py --source ../x402-avm-js/src/index.ts
python scripts/sync_examples.py --examples ../examples
```
