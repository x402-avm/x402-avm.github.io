These docs are written for two kinds of reader: people, and AI agents that act on their behalf. This section covers both sides of the agent story.

## Agents that pay for tools

An AI agent, such as an MCP client, an autonomous workflow or a coding agent, can call paid MCP tools by holding an Algorand key and opening a `paid_mcp_session`. Every paid call is a small, exact, on-chain payment that settles only if the tool succeeds.

What makes this workable for unattended agents:

- **No accounts or API keys to provision.** A funded Algorand address is enough to call any x402 tool.
- **Bounded per-payment risk.** Spend controls refuse any payment above a cap, or in an unexpected asset, before anything is signed.
- **No charge for failures.** A tool that errors is not charged, so an agent's retries do not double-pay for failures.
- **No replays.** Each signed payment buys exactly one call.
- **Exact amounts.** The buyer's balance drops by the price; the server pays the network fee.

## Quick reference for agents

| Fact | Value |
|---|---|
| Python client | `from ai_economy_sdk import paid_mcp_session` |
| Default spend cap | `$1` per payment: 1,000,000 base units of ALGO or USDC |
| Default allowed assets | ALGO (`"0"`) on any Algorand network; USDC `"31566704"` (MainNet), `"10458941"` (TestNet) |
| Challenge header (server to client) | `PAYMENT-REQUIRED` (base64 JSON, x402 version 2) |
| Payment header (client to server) | `PAYMENT-SIGNATURE` (base64 JSON) |
| Identity headers | `X-Identity-Txn`, or `x-sender-address` / `x-sender-timestamp` / `x-sender-signature` |
| MainNet id | `algorand:wGHE2Pwdvd7S12BL5FaOP20EGYesN73k` |
| TestNet id | `algorand:SGO1GKSzyE7IEPItTxCByw9x8FmnrCDe` |
| Full docs as one file | [`https://x402-avm.github.io/llms-full.txt`](https://x402-avm.github.io/llms-full.txt) |
