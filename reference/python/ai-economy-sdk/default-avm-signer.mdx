```python Signature
class DefaultAvmSigner(private_key: str, algod_client=None)
```

A default implementation of AvmSigner for convenience.

Wraps an Algorand account private key and an optional AlgodClient connection
to handle signing and submitting single transactions or atomic transaction groups.

## Constructor parameters

<ParamField body="private_key" type="str" required>
Base64-encoded 32-byte Algorand private key.
</ParamField>

<ParamField body="algod_client" type="algosdk.v2client.algod.AlgodClient" default="None">
Connected algod client used for group simulation, transmission, and confirmation.
Default is None.
</ParamField>

## Attributes

<ResponseField name="private_key" type="str">
The signing key.
</ResponseField>

<ResponseField name="address" type="str">
The corresponding Algorand public address.
</ResponseField>

<ResponseField name="algod_client" type="algosdk.v2client.algod.AlgodClient or None">
Client used for on-chain interactions.
</ResponseField>
