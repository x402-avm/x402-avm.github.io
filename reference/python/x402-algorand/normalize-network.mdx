Normalize network identifier to CAIP-2 format.

## Parameters

<ParamField body="network" type="str" required>
Network identifier (V1 name, legacy long CAIP-2, or short CAIP-2).
</ParamField>

## Returns

<ResponseField name="returns" type="str">
CAIP-2 network identifier.
</ResponseField>

## Raises

- `NetworkError`: If network is not supported or invalid format (subclass of `ValueError`).

## Examples
