Register a custom Algorand network (e.g. LocalNet or private network).

Computes the CAIP-2 identifier, updates NETWORK_CONFIGS, GENESIS_HASH_TO_NETWORK,
and SUPPORTED_NETWORKS.

## Parameters

<ParamField body="genesis_hash" type="str | bytes" required>
32-byte genesis hash (base64 string or raw bytes).
</ParamField>

<ParamField body="genesis_id" type="str" default="''">
Genesis ID string (e.g. "dockernet-v1").
</ParamField>

<ParamField body="algod_url" type="str | None" default="None">
Algod endpoint URL (defaults to "http://localhost:4001").
</ParamField>

<ParamField body="indexer_url" type="str | None" default="None">
Indexer endpoint URL (defaults to "http://localhost:8980").
</ParamField>

## Returns

<ResponseField name="returns" type="str">
The registered CAIP-2 network identifier.
</ResponseField>
