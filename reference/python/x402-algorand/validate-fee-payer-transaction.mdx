Validate a fee payer transaction.

Per spec, fee payer transaction must be:
- Type "pay" (payment)
- Sender is the fee payer
- Receiver is the fee payer (self-payment)
- Amount is 0 (no value transfer)
- No close-to field
- No rekey field
- Fee is reasonable (covers pooled fees)
