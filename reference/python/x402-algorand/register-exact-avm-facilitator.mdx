Register AVM exact payment schemes to x402Facilitator.

Registers:
- V2: Specified networks
- V1: All supported AVM networks

## Parameters

<ParamField body="facilitator" type="FacilitatorT" required>
x402Facilitator instance.
</ParamField>

<ParamField body="signer" type="FacilitatorAvmSigner" required>
AVM signer for verification/settlement.
</ParamField>

<ParamField body="networks" type="str | list[str]" required>
Network(s) to register.
</ParamField>

## Returns

<ResponseField name="returns" type="FacilitatorT">

## Examples

```python
import os

from algosdk.v2client.algod import AlgodClient
from x402 import x402Facilitator
from x402_algorand import ServerAvmSigner, caip2_from_genesis_hash
from x402_algorand.exact import register_exact_avm_facilitator

algod = AlgodClient("a" * 64, "http://localhost:4001")  # LocalNet
network = caip2_from_genesis_hash(algod.suggested_params().gh)
signer = ServerAvmSigner.from_mnemonic(os.environ["FACILITATOR_MNEMONIC"], algod)

facilitator = x402Facilitator()
register_exact_avm_facilitator(facilitator, signer, network)
```
