A signer could not sign: bad key material or an address it does not manage.

## Examples

```python
from x402_algorand import PayerAvmSigner, SigningError

try:
    PayerAvmSigner.from_mnemonic("not a valid mnemonic")
except SigningError as e:  # also a ValueError; the message never contains key material
    print(e)  # invalid 25-word Algorand mnemonic
```
