An algod node is connected to a different network than the one requested.

## Examples

```python
import os

from algosdk.v2client.algod import AlgodClient
from x402_algorand import ALGORAND_MAINNET_CAIP2, NetworkMismatchError, ServerAvmSigner

local = AlgodClient("a" * 64, "http://localhost:4001")  # a LocalNet node
signer = ServerAvmSigner.from_mnemonic(os.environ["FACILITATOR_MNEMONIC"], local)
try:
    signer.algod_for(ALGORAND_MAINNET_CAIP2)  # the node is not on MainNet
except NetworkMismatchError as e:
    print(e)  # algod is on algorand:... but the request is for algorand:wGHE2Pwdvd7S12BL5FaOP20EGYesN73k
```
