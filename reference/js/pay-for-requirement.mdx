Helper to execute full payment flow for an x402 payment challenge.

Automates the complete client payment workflow:
1. Fetches current suggested transaction parameters from the algod client.
2. Matches the requirement against the active algod network using `selectRequirement`.
3. Builds the exact AVM atomic transaction group via `buildExactAvmGroup`.
4. Calls `signTxns` for the transaction indexes requiring payer signature.
5. Assembles signed and unsigned transactions and encodes the `PAYMENT-SIGNATURE` header.

<ParamField body="paymentRequired" type="PaymentRequired | any" required>

</ParamField>

<ParamField body="payerAddress" type="string" required>

<ParamField body="algod" type="algosdk.Algodv2" required>
Algodv2 client instance for the active network.
</ParamField>

<ParamField body="signTxns" type="(txns: Uint8Array[], indexes: number[]) => Promise<(Uint8Array | null)[]>" required>
Callback function that signs unsigned transaction byte arrays for specified indexes.
</ParamField>

## Returns

<ResponseField name="returns" type="Promise<string>">
Promise resolving to the base64-encoded `PAYMENT-SIGNATURE` header string.
</ResponseField>

## Throws

- `Error`: If parameter fetching fails, requirement matching fails, or signing is rejected.
