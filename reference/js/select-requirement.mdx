```ts Signature
export function selectRequirement(paymentRequired: Pick<PaymentRequired, 'accepts'>, network: string): PaymentRequirements;
```

Select the first acceptable payment requirement matching the payer's network.

Searches the `accepts` array of a PaymentRequired challenge for an offer using the "exact"
payment scheme matching the specified network (resolved via `resolveNetwork`).

## Parameters

<ParamField body="paymentRequired" type="Pick<PaymentRequired, 'accepts'>" required>
Parsed PaymentRequired object (anything with an `accepts` array).
</ParamField>

<ParamField body="network" type="string" required>
Desired network name, alias, or CAIP-2 identifier.
</ParamField>

## Returns

<ResponseField name="returns" type="PaymentRequirements">
The matching PaymentRequirements entry.
</ResponseField>

## Throws

- `NoSupportedRequirementError`: If `accepts` is empty.
- `NetworkMismatchError`: If no requirement matches the requested network.

## Example

```ts
const req = selectRequirement(paymentRequired, 'mainnet');
console.log(`Pay ${req.amount} microALGO to ${req.payTo}`);
```
