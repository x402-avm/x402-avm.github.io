Create an Algodv2 client for a named network or custom endpoint.

Connects to public AlgoNode endpoints for "mainnet" and "testnet", or default
credentials (port 4001, token of 64 'a's) for "localnet". For private networks,
pass the node's URL explicitly.

## Parameters

<ParamField body="network" type="string" required>
Network name ('mainnet', 'testnet', 'localnet', or CAIP-2 string).
</ParamField>

<ParamField body="url" type="string">
Optional custom algod base URL.
</ParamField>

<ParamField body="token" type="string">
Optional authentication token or header.
</ParamField>

## Returns

<ResponseField name="returns" type="algosdk.Algodv2">
Configured Algodv2 client.
</ResponseField>

## Throws

- `Error`: If network has no default endpoint and url is omitted.

## Example

```ts
const client = algodClient('testnet');
const localClient = algodClient('localnet');
```
