Encode a payment payload into a base64-encoded PAYMENT-SIGNATURE header.

Constructs the standard x402 v2 payment response object containing `accepted` requirements,
the base64-encoded transaction group (signed or unsigned), the `paymentIndex`, and any
resource or extensions metadata copied from the original challenge.

## Parameters

<ParamField body="paymentRequired" type="PaymentRequired" required>
The original PaymentRequired challenge object.
</ParamField>

<ParamField body="accepted" type="PaymentRequirements" required>
The selected and fulfilled PaymentRequirements item.
</ParamField>

<ParamField body="groupB64" type="string[]" required>
Array of base64-encoded transactions (signed bytes or unsigned fallback).
</ParamField>

<ParamField body="paymentIndex" type="number" required>
0-based index of the payment transaction within the group.
</ParamField>

## Returns

<ResponseField name="returns" type="string">
Base64-encoded string ready to pass in the `PAYMENT-SIGNATURE` HTTP header.
</ResponseField>

## Example

```ts
const header = encodePaymentHeader(challenge, accepted, groupB64, paymentIndex);
const response = await fetch(url, {
  headers: { 'PAYMENT-SIGNATURE': header }
});
```
