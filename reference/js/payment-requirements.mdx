Payment requirements specified by an x402 server.

Defines the scheme, CAIP-2 network, asset ID (0 for ALGO), amount in base units,
recipient address, timeout, and optional extra metadata such as fee payer and token decimals.

## Properties

<ResponseField name="scheme" type="string" required>
Payment scheme identifier. x402-avm-js builds payments for `"exact"`.
</ResponseField>

<ResponseField name="network" type="string" required>
CAIP-2 network id, for example `algorand:wGHE2Pwdvd7S12BL5FaOP20EGYesN73k` for MainNet.
</ResponseField>

<ResponseField name="asset" type="string" required>
Asset id as a string: `"0"` for native ALGO, otherwise the ASA id (for example `"31566704"` for USDC on MainNet).
</ResponseField>

<ResponseField name="amount" type="string" required>
Amount in the asset's base units (microALGO for ALGO), as a string.
</ResponseField>

<ResponseField name="payTo" type="string" required>
Algorand address (58 characters) that receives the payment.
</ResponseField>

<ResponseField name="maxTimeoutSeconds" type="number" required>
Maximum time, in seconds, the server allows for the payment.
</ResponseField>

<ResponseField name="extra" type="object">
Optional scheme metadata sent by the server.

<Expandable title="properties">

<ResponseField name="feePayer" type="string">
Address of the server account that pays the group's fees. When present, `buildExactAvmGroup` builds the two-transaction group.
</ResponseField>

<ResponseField name="decimals" type="number">
Decimals of the asset.
</ResponseField>

<ResponseField name="genesisHash" type="string">
Base64 genesis hash of the network.
</ResponseField>

<ResponseField name="genesisId" type="string">
Genesis id of the network, for example `mainnet-v1.0`.
</ResponseField>

<ResponseField name="[key: string]" type="any">
Any other field the server sends.
</ResponseField>

</Expandable>
</ResponseField>
