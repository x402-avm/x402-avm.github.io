Decode a base64-encoded PAYMENT-REQUIRED header value into a PaymentRequired object.

Parses the base64-encoded JSON payload received in an HTTP 402 response into a typed
PaymentRequired structure without relying on Node.js binary APIs.

## Parameters

<ParamField body="headerB64" type="string" required>
Base64-encoded string from the PAYMENT-REQUIRED response header.
</ParamField>

## Returns

<ResponseField name="returns" type="PaymentRequired">
Decoded PaymentRequired object.
</ResponseField>

## Throws

- `InvalidPaymentRequiredError`: If decoding or JSON parsing fails, or the decoded shape is invalid.

## Example

```ts
const header = response.headers.get('PAYMENT-REQUIRED');
const challenge = decodePaymentRequired(header);
console.log(challenge.x402Version); // 2
```
