Decoded payload of the HTTP 402 PAYMENT-REQUIRED header.

Contains the x402 protocol version (2), optional error string, protected resource info,
list of acceptable payment requirements, and optional extensions.

## Properties

<ResponseField name="x402Version" type="number" required>
x402 protocol version (2).
</ResponseField>

<ResponseField name="error" type="string | null">
Optional error message from the server.
</ResponseField>

<ResponseField name="resource" type="ResourceInfo | null">
The protected resource.
</ResponseField>

<ResponseField name="accepts" type="PaymentRequirements[]" required>
The payment offers the server accepts. `selectRequirement` and `payForRequirement` pick the `exact` offer for the wallet's network.
</ResponseField>

<ResponseField name="extensions" type="Record<string, any> | null">
Optional protocol extensions. `encodePaymentHeader` copies them into the payment payload.
</ResponseField>
