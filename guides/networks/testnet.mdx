TestNet is a public Algorand network whose ALGO has no value. Payments are real transactions that anyone can see in an explorer, so TestNet is the place to check a deployment before MainNet.

| | |
|---|---|
| Short name | `testnet` |
| CAIP-2 id | `algorand:SGO1GKSzyE7IEPItTxCByw9x8FmnrCDe` |
| Genesis hash | `SGO1GKSzyE7IEPItTxCByw9x8FmnrCDexi9/cOUJOiI=` |
| Default algod | `https://testnet-api.algonode.cloud` |
| Default indexer | `https://testnet-idx.algonode.cloud` |
| USDC asset id | `10458941` |
| Constants | Python `ai_economy_sdk.TESTNET`, JavaScript `TESTNET` |

<Steps>
  <Step title="Create two accounts">
    You need a server account (it receives payments and pays the group fees) and a buyer account.

    ```python
    from algosdk import account, mnemonic

    for role in ("server", "buyer"):
        sk, addr = account.generate_account()
        print(role, addr)
        print(role, "mnemonic:", mnemonic.from_private_key(sk))
    ```

    Store the mnemonics in a secret store or environment variables, not in code. `mnemonic.to_private_key(...)` turns a mnemonic back into the base64 private key the SDK expects.
  </Step>
  <Step title="Fund them with free TestNet ALGO">
    Open the TestNet dispenser at [lora.algokit.io/testnet/fund](https://lora.algokit.io/testnet/fund), and send ALGO to both addresses. A few ALGO each is plenty:

    - The server pays 2,000 microALGO of fees per settled call, so 1 ALGO covers 500 calls.
    - Every account must keep a minimum balance of 0.1 ALGO, plus 0.1 ALGO per asset it opts in to.
  </Step>
  <Step title="Run the server on TestNet">
    Compared with the [Quickstart](/quickstart) server, only the network, the algod client and the key source change:

    ```python server_testnet.py
    import os

    import uvicorn
    from algosdk import account, mnemonic
    from algosdk.v2client import algod
    from fastmcp import FastMCP
    from ai_economy_sdk import DefaultAvmSigner, PaymentGate

    server_sk = mnemonic.to_private_key(os.environ["SERVER_MNEMONIC"])
    server_addr = account.address_from_private_key(server_sk)
    algod_client = algod.AlgodClient("", "https://testnet-api.algonode.cloud")

    mcp = FastMCP("TestNetServer")

    @mcp.tool()
    def echo(text: str) -> str:
        """Echo back input text."""
        return f"echo: {text}"

    gate = PaymentGate(
        signer=DefaultAvmSigner(server_sk, algod_client=algod_client),
        network="testnet",
        pay_to=server_addr,
        asset_id=0,
        prices={"echo": 5000},
    )
    uvicorn.run(gate.wrap(mcp), host="127.0.0.1", port=9201)
    ```
  </Step>
  <Step title="Pay from the client">
    `paid_mcp_session` uses the public TestNet algod when `network="testnet"`:

    ```python client_testnet.py
    import asyncio
    import os

    from algosdk import mnemonic
    from ai_economy_sdk import paid_mcp_session

    async def main() -> None:
        buyer_sk = mnemonic.to_private_key(os.environ["BUYER_MNEMONIC"])
        async with paid_mcp_session("http://127.0.0.1:9201/sse", buyer_sk, "testnet") as session:
            result = await session.call_tool("echo", {"text": "hello testnet"})
            print(result.content[0].text)

    asyncio.run(main())
    ```

    Look up the buyer or server address in the [Lora explorer](https://lora.algokit.io/testnet) to see the settled group: a 0-ALGO fee payer transaction with a 2,000 microALGO fee, and the buyer's 5,000 microALGO payment.
  </Step>
</Steps>

<Note>

## A real TestNet payment

[`testnet/live_payment.py`](https://github.com/x402-avm/examples/blob/main/testnet/live_payment.py) makes one real payment of 1,000 microALGO on TestNet: it builds the payment with the client scheme, verifies it with the facilitator scheme, and settles it with the server account as fee payer. It only does this when both mnemonics are set; otherwise it prints instructions and exits with status 0.

```bash
export TESTNET_BUYER_MNEMONIC="..."    # buyer, funded at lora.algokit.io/testnet/fund
export TESTNET_SERVER_MNEMONIC="..."   # receiver and fee payer, also funded
python testnet/live_payment.py
```

It prints the confirmed transaction id and a Lora explorer link.

{/* example: testnet/live_payment.py */}

```python testnet/live_payment.py expandable
"""Optional live TestNet payment execution for x402 on Algorand.

Performs a real payment on TestNet ONLY when explicit environment variables are set:
  TESTNET_BUYER_MNEMONIC: 25-word mnemonic for buyer account on TestNet
  TESTNET_SERVER_MNEMONIC: 25-word mnemonic for server / fee-payer account on TestNet

TestNet ALGO can be obtained for free from the official dispenser:
  https://lora.algokit.io/testnet/fund

If the environment variables are not set, this script prints instructions and
exits cleanly with status code 0.

How to run:
    python testnet/live_payment.py
"""

import os
import sys
from algosdk import mnemonic, transaction
from algosdk.v2client import algod

from x402.schemas import PaymentPayload, PaymentRequirements
from x402_algorand.constants import ALGORAND_TESTNET_CAIP2
from x402_algorand.exact.client import ExactAvmScheme as ClientScheme
from x402_algorand.exact.facilitator import ExactAvmScheme as FacilitatorScheme
from ai_economy_sdk import DefaultAvmSigner

ALGOD_URL = "https://testnet-api.algonode.cloud"
AMOUNT_MICROALGO = 1000  # 0.001 ALGO


def main():
    buyer_mn = os.environ.get("TESTNET_BUYER_MNEMONIC")
    server_mn = os.environ.get("TESTNET_SERVER_MNEMONIC")

    if not buyer_mn or not server_mn:
        print("TestNet live payment example requires environment variables:")
        print("  TESTNET_BUYER_MNEMONIC: 25-word mnemonic for buyer account on TestNet")
        print("  TESTNET_SERVER_MNEMONIC: 25-word mnemonic for server account on TestNet")
        print()
        print("TestNet ALGO can be obtained for free from https://lora.algokit.io/testnet/fund.")
        print("Environment variables not set; skipping live on-chain payment.")
        sys.exit(0)

    print("Initializing TestNet clients and accounts...")
    client = algod.AlgodClient("", ALGOD_URL)

    buyer_sk = mnemonic.to_private_key(buyer_mn)
    buyer_addr = mnemonic.to_public_key(buyer_mn)

    server_sk = mnemonic.to_private_key(server_mn)
    server_addr = mnemonic.to_public_key(server_mn)

    print(f"Buyer address:  {buyer_addr}")
    print(f"Server address: {server_addr}")

    buyer_signer = DefaultAvmSigner(buyer_sk, algod_client=client)
    server_signer = DefaultAvmSigner(server_sk, algod_client=client)

    client_scheme = ClientScheme(buyer_signer, algod_url=ALGOD_URL)
    facilitator_scheme = FacilitatorScheme(server_signer)

    requirements = PaymentRequirements(
        scheme="exact",
        network=ALGORAND_TESTNET_CAIP2,
        asset="0",
        amount=str(AMOUNT_MICROALGO),
        pay_to=server_addr,
        max_timeout_seconds=300,
        extra={"feePayer": server_addr},
    )

    print(f"\nConstructing payment for {AMOUNT_MICROALGO} microALGO...")
    inner_payload = client_scheme.create_payment_payload(requirements)
    payload = PaymentPayload(x402_version=2, payload=inner_payload, accepted=requirements)

    print("Verifying payment payload with facilitator...")
    verify_res = facilitator_scheme.verify(payload, requirements)
    if not verify_res.is_valid:
        print(f"Verification failed: {verify_res.invalid_reason}")
        sys.exit(1)

    print("Submitting and settling atomic group on TestNet...")
    settle_res = facilitator_scheme.settle(payload, requirements)
    if not settle_res.success:
        print(f"Settlement failed: {settle_res.error_reason}")
        sys.exit(1)

    txid = settle_res.transaction
    print(f"Confirmed transaction ID: {txid}")
    print(f"View in explorer: https://lora.algokit.io/testnet/transaction/{txid}")


if __name__ == "__main__":
    main()
```

## Accept TestNet USDC

To price tools in USDC on TestNet:

1. **Opt both accounts in.** The server's `pay_to` account and every buyer must opt in to asset `10458941` before they can hold it. An opt-in is a 0-amount asset transfer to yourself:

   ```python
   from algosdk.transaction import AssetTransferTxn, wait_for_confirmation

   def opt_in(algod_client, address: str, private_key: str, asset_id: int) -> None:
       sp = algod_client.suggested_params()
       txn = AssetTransferTxn(sender=address, sp=sp, receiver=address, amt=0, index=asset_id)
       txid = algod_client.send_transaction(txn.sign(private_key))
       wait_for_confirmation(algod_client, txid, 4)
   ```

2. **Get TestNet USDC** into the buyer account, for example from Circle's testnet faucet at [faucet.circle.com](https://faucet.circle.com).
3. **Price in base units.** USDC has 6 decimals, so `50_000` is 0.05 USDC:

   ```python
   from ai_economy_sdk import TESTNET, PaymentGate, usdc_asset_id

   gate = PaymentGate(
       signer=signer,
       network=TESTNET,
       pay_to=server_addr,
       asset_id=usdc_asset_id(TESTNET),  # 10458941
       default_price=50_000,             # 0.05 USDC per call
   )
   ```

The fee floor that protects ALGO prices does not apply to USDC prices. The server still pays the group's fees in ALGO, so keep ALGO in the server account. Clients need no change: the default spend controls of the `x402` client allow USDC on TestNet, up to 1 USDC per payment.

## Check payments without funds

You can validate payment groups against live TestNet state without keys or funds: build the group, then ask algod to simulate it with empty signatures. Both examples find real funded accounts through the public indexer and simulate four cases: ALGO and USDC (`10458941`), each with and without a fee payer. The MainNet versions are in the [MainNet guide](/guides/networks/mainnet#simulate-on-mainnet).

<Tabs>
  <Tab title="Python">
    {/* example: testnet/simulate.py */}

    ```python testnet/simulate.py expandable
    """Public network simulation for x402 Algorand payments on TestNet.

    Performs read-only validation against real TestNet ledger without spending funds:
    1. Queries the public AlgoNode indexer to identify real funded accounts holding USDC and ALGO.
    2. Constructs payment groups for ALGO (asset 0) and USDC (asset 10458941), both with and without fee payers.
    3. Evaluates the constructed atomic groups via Algod's simulate endpoint using empty signatures.
    4. Confirms that all 4 test cases simulate successfully without on-chain execution.

    How to run:
        python testnet/simulate.py

    What it prints:
        Network progress and "ok" for each of the 4 test cases.
    """

    import httpx
    from algosdk import encoding, transaction
    from algosdk.v2client import algod
    from algosdk.v2client.models import SimulateRequest, SimulateRequestTransactionGroup

    from x402.schemas import PaymentRequirements
    from x402_algorand.constants import ALGORAND_TESTNET_CAIP2
    from x402_algorand.exact.client import ExactAvmScheme as ExactAvmClient

    CONFIG = {
        "name": "testnet",
        "caip": ALGORAND_TESTNET_CAIP2,
        "algod_url": "https://testnet-api.algonode.cloud",
        "indexer_url": "https://testnet-idx.algonode.cloud",
        "usdc_id": 10458941,
    }


    class _WatchOnly:
        """Watch-only signer providing an address without private keys.

        Generates unsigned transactions for simulate endpoint evaluation.
        """

        def __init__(self, address: str):
            self.address = address

        def sign_transactions(self, txns: list[bytes], indexes: list[int]) -> list[None]:
            return [None] * len(txns)


    def get_algod(cfg: dict) -> algod.AlgodClient:
        return algod.AlgodClient("", cfg["algod_url"])


    def find_funded_holders(cfg: dict, n: int = 3) -> list[str]:
        """Find real funded accounts holding ALGO and USDC via public indexer."""
        client = get_algod(cfg)
        idx_url = cfg["indexer_url"]
        usdc_id = cfg["usdc_id"]

        resp = httpx.get(
            f"{idx_url}/v2/assets/{usdc_id}/balances",
            params={"currency-greater-than": 5_000_000, "limit": 40},
            timeout=20,
        )
        balances = resp.json().get("balances", [])
        out = []
        for b in balances:
            try:
                info = client.account_info(b["address"])
                if info["amount"] - info["min-balance"] > 2_000_000 and not info.get("auth-addr"):
                    out.append(b["address"])
                    if len(out) == n:
                        return out
            except Exception:
                continue
        raise RuntimeError(f"Could not find {n} funded USDC holders on {cfg['name']}")


    def simulate_group(client: algod.AlgodClient, group_b64: list[str]) -> str | None:
        """Run transaction group through Algod simulation with empty signatures."""
        stx = []
        for b in group_b64:
            d = encoding.msgpack_decode(b)
            stx.append(
                d
                if isinstance(d, transaction.SignedTransaction)
                else transaction.SignedTransaction(d, None)
            )
        req = SimulateRequest(
            txn_groups=[SimulateRequestTransactionGroup(txns=stx)],
            allow_empty_signatures=True,
        )
        res = client.simulate_transactions(req)
        return res["txn-groups"][0].get("failure-message")


    def main():
        net_name = CONFIG["name"]
        caip = CONFIG["caip"]
        print(f"Testing {net_name} ({caip})...")

        holders = find_funded_holders(CONFIG, n=3)
        payer, pay_to, fp = holders
        client = get_algod(CONFIG)

        test_cases = [
            ("ALGO", "0", True),
            ("ALGO", "0", False),
            ("USDC", str(CONFIG["usdc_id"]), True),
            ("USDC", str(CONFIG["usdc_id"]), False),
        ]

        for asset_name, asset_id, fee_payer in test_cases:
            extra = {"feePayer": fp} if fee_payer else {}
            req = PaymentRequirements(
                scheme="exact",
                network=caip,
                asset=asset_id,
                amount="10000",
                pay_to=pay_to,
                max_timeout_seconds=300,
                extra=extra,
            )

            avm_client = ExactAvmClient(_WatchOnly(payer), algod_url=CONFIG["algod_url"])
            payload = avm_client.create_payment_payload(req)
            failure = simulate_group(client, payload["paymentGroup"])
            assert failure is None, f"Simulation failed on {net_name} {asset_name} (fee_payer={fee_payer}): {failure}"
            print(f"  {net_name} {asset_name} (fee_payer={fee_payer}): ok")

        print(f"All {net_name} simulations passed successfully.")


    if __name__ == "__main__":
        main()
    ```

  <Tab title="JavaScript">
    {/* example: testnet/simulate.mjs */}

    ```javascript testnet/simulate.mjs expandable
    /**
     * Read-only simulation of ALGO and USDC payments on Algorand TestNet.
     *
     * Demonstrates:
     * 1. Discovering real funded USDC holders via public AlgoNode indexer endpoints.
     * 2. Building exact AVM payment groups using a watch-only signer (empty signatures).
     * 3. Verifying transaction group validity on live TestNet nodes using algod.simulateTransactions().
     * 4. Verifying both native ALGO and ASA USDC transfers, with and without fee payers.
     *
     * How to run:
     *   node testnet/simulate.mjs
     *
     * What it prints:
     *   Found account addresses on TestNet and "ok" for each simulated payment scenario.
     */

    import algosdk from 'algosdk';
    import {
      TESTNET,
      algodClient,
      payForRequirement,
    } from 'x402-avm-js';

    async function fundedUsdcHolders(net, algod) {
      const url = `${net.indexerUrl}/v2/assets/${net.usdc}/balances?currency-greater-than=5000000&limit=40`;
      const res = await fetch(url);
      if (!res.ok) {
        throw new Error(`Indexer query failed with status ${res.status}`);
      }
      const rows = (await res.json()).balances;
      const out = [];
      for (const row of rows) {
        const info = await algod.accountInformation(row.address).do();
        if (info.amount - info.minBalance > 2_000_000n && !info.authAddr) {
          out.push(row.address);
        }
        if (out.length === 3) return out;
      }
      throw new Error(`Not enough funded USDC holders found on ${net.genesisId}`);
    }

    async function main() {
      const name = 'testnet';
      const net = TESTNET;
      console.log(`Testing ${name} (${net.caip2})...`);
      const algod = algodClient(name);

      const [payer, payTo, feePayer] = await fundedUsdcHolders(net, algod);
      console.log(`Discovered active accounts:`);
      console.log(`  Payer:     ${payer}`);
      console.log(`  PayTo:     ${payTo}`);
      console.log(`  Fee payer: ${feePayer}`);

      const cases = [
        { asset: 'ALGO', assetId: '0', withFeePayer: true },
        { asset: 'ALGO', assetId: '0', withFeePayer: false },
        { asset: 'USDC', assetId: String(net.usdc), withFeePayer: true },
        { asset: 'USDC', assetId: String(net.usdc), withFeePayer: false },
      ];

      for (const c of cases) {
        const requirement = {
          scheme: 'exact',
          network: net.caip2,
          asset: c.assetId,
          amount: '10000',
          payTo,
          maxTimeoutSeconds: 300,
          extra: c.withFeePayer ? { feePayer } : {},
        };

        const emptySigner = async (txns) => txns.map(() => null);

        const challenge = {
          x402Version: 2,
          accepts: [requirement],
        };

        const paymentSignatureHeader = await payForRequirement(challenge, payer, algod, emptySigner);
        const decoded = JSON.parse(new TextDecoder().decode(algosdk.base64ToBytes(paymentSignatureHeader)));

        const txns = decoded.payload.paymentGroup.map(
          (b64) =>
            new algosdk.SignedTransaction({
              txn: algosdk.decodeUnsignedTransaction(algosdk.base64ToBytes(b64)),
            })
        );

        const sim = await algod
          .simulateTransactions(
            new algosdk.modelsv2.SimulateRequest({
              txnGroups: [new algosdk.modelsv2.SimulateRequestTransactionGroup({ txns })],
              allowEmptySignatures: true,
            })
          )
          .do();

        const failure = sim.txnGroups[0].failureMessage ?? null;
        if (failure) {
          throw new Error(`Simulation failed on ${name} ${c.asset} (withFeePayer=${c.withFeePayer}): ${failure}`);
        }

        console.log(`  ${name} ${c.asset} (fee_payer=${c.withFeePayer}): ok`);
      }

      console.log(`All ${name} simulations passed successfully.`);
    }

    main().catch((err) => {
      console.error('TestNet simulation failed:', err);
      process.exit(1);
    });
    ```
