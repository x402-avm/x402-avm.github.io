A server needs the caller's address for passes, subscriptions, bulk discounts and per-caller prices. The caller proves it by signing something with its key. Nothing is submitted to the chain and nothing is paid.

## Two formats

| Format | Headers | Create with | Used by |
|---|---|---|---|
| Identity transaction (recommended) | `X-Identity-Txn` | `sign_identity_txn` (Python), `buildIdentityTxn` + `encodeIdentityHeader` (JavaScript) | Browser wallets and any client that can sign Algorand transactions |
| Legacy signature | `x-sender-address`, `x-sender-timestamp`, `x-sender-signature` | `sign_identity` (Python) | `paid_mcp_session` (sent on every request when `identity=True`) |

`PaymentGate` verifies both with `verify_identity`: it checks `X-Identity-Txn` first, against the gate's network, and falls back to the legacy headers.

## The identity transaction

Browser wallets sign transactions, not arbitrary bytes, so the proof is a transaction that can never execute. `make_identity_txn` builds it as:

| Field | Value | Why |
|---|---|---|
| type | `pay` | An ordinary payment the wallet can display and sign |
| sender, receiver | the caller | A self-payment moves nothing |
| amount | 0 | |
| fee | 0 | Below the network minimum, so it cannot be confirmed |
| first valid, last valid | 1, 1000 | A window every live network has passed |
| genesis hash | the network's | Binds the proof to one network |
| note | `x402-identity:<address>:<unix timestamp>` | Binds the proof to the caller and a time |

The caller signs it, msgpack-encodes the signed transaction, base64-encodes the bytes and sends them as `X-Identity-Txn`.

### Verification rules

`verify_identity_txn(header_value, expected_genesis_hash_b64, max_skew=120)` returns the address, or `None` if any check fails:

1. The header decodes to a signed transaction with a plain Ed25519 signature: no multisig, no logic signature, no rekeyed (authorized) signer.
2. Type `pay`, sender equals receiver, amount 0, fee 0, no close-to, no rekey-to.
3. The genesis hash equals the expected one.
4. The validity window is at most 1,000 rounds.
5. The note is `x402-identity:<sender>:<integer timestamp>` and the timestamp is within `max_skew` seconds of the server's clock.
6. The signature verifies against the sender's public key.

## The legacy headers

`sign_identity(private_key)` signs the message `x402-identity:<address>:<timestamp>` with Ed25519 (algosdk's `sign_bytes`) and returns the three `x-sender-*` headers. `verify_identity` checks the address, the 120-second skew and the signature. Use them from servers and agents that hold a raw key; use `X-Identity-Txn` from wallets.

## Create and verify

<CodeGroup>
```python Python
from ai_economy_sdk import genesis_hash_for, sign_identity_txn, verify_identity_txn

gh = genesis_hash_for("mainnet")

# Client: one header, {"X-Identity-Txn": "..."}
headers = sign_identity_txn(client_private_key, gh)

# Server: the address, or None
address = verify_identity_txn(headers["X-Identity-Txn"], gh)
```

```ts JavaScript (client)
import algosdk from 'algosdk';
import { buildIdentityTxn, encodeIdentityHeader, MAINNET } from 'x402-avm-js';

const txn = buildIdentityTxn(myAddress, MAINNET.genesisHash);
const [signed] = await wallet.signTransactions([algosdk.encodeUnsignedTransaction(txn)], [0]);
const headers = { 'X-Identity-Txn': encodeIdentityHeader(signed!) };
```
</CodeGroup>

`x402-avm-js` creates proofs but does not verify them. Verify on the server with `verify_identity_txn` or `verify_identity`.

## Complete example

The example signs a proof for the current LocalNet, verifies it, and shows that a different genesis hash is rejected.

{/* example: localnet/identity.py */}

```python localnet/identity.py expandable
"""Identity proof verification via zero-fee self-signed Algorand transactions.

Demonstrates sign_identity_txn and verify_identity_txn:
1. Generates an account and constructs an X-Identity-Txn header bound to the network genesis hash.
2. Verifies the header on the receiver side, asserting the recovered address matches the signer.
3. Proves that verifying with a mismatched genesis hash rejects the signature (returns None).

How to run:
    python localnet/identity.py

What it prints:
    Address: <44-character Algorand address>
    Verified address matches: True
    Wrong genesis hash rejected: True
"""
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent))

from algosdk import account
from ai_economy_sdk import sign_identity_txn, verify_identity_txn
from _localnet import ALGOD

WRONG_GENESIS_HASH = "AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA="


def main() -> None:
    sk, addr = account.generate_account()
    print(f"Address: {addr}")

    # Read current LocalNet genesis hash
    sp = ALGOD.suggested_params()
    current_gh = sp.gh

    # 1. Sign identity proof for the current network
    headers = sign_identity_txn(sk, current_gh)

    # 2. Verify with matching genesis hash
    verified_address = verify_identity_txn(headers["X-Identity-Txn"], current_gh)
    matches = verified_address == addr
    print(f"Verified address matches: {matches}")

    # 3. Attempt verification with mismatched genesis hash
    rejected = verify_identity_txn(headers["X-Identity-Txn"], WRONG_GENESIS_HASH)
    print(f"Wrong genesis hash rejected: {rejected is None}")


if __name__ == "__main__":
    main()
```
