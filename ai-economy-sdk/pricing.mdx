Prices are integers in the base units of the gate's asset: microALGO when `asset_id=0`, or the ASA's base units (for USDC, 10<sup>-6</sup> USDC). A price of 0 makes a call free and skips the payment challenge.

## Fixed price for every tool

```python
gate = PaymentGate(
    signer=signer,
    network="localnet",
    pay_to=server_address,
    asset_id=0,
    default_price=5000,  # 5,000 microALGO for every tool
)
```

## Per-tool prices

```python
gate = PaymentGate(
    signer=signer,
    network="localnet",
    pay_to=server_address,
    asset_id=0,
    prices={
        "status": 0,            # free
        "generate_text": 15000, # 0.015 ALGO
        "render_chart": 25000,  # 0.025 ALGO
    },
    default_price=5000,         # tools not listed
)
```

## Dynamic prices

Pass a callable instead of a dictionary. It receives the tool name, the call's arguments and the caller's verified address (`None` when the caller sent no valid identity proof), and returns the price.

```python
def dynamic_price(tool: str, args: dict, sender: str | None) -> int:
    if tool == "transcribe":
        seconds = float(args.get("duration", 0))
        return 3000 + int(seconds * 50)          # base + 50 microALGO per second
    if tool == "inference":
        tokens = int(args.get("max_tokens", 100))
        rate = 10 if sender == PARTNER_ADDRESS else 25
        return 4000 + tokens * rate
    return 5000

gate = PaymentGate(signer=signer, network="localnet", pay_to=server_address, asset_id=0, prices=dynamic_price)
```

The price is computed before the `402` is sent, so the client sees the exact amount for this call.

## Bulk discounts

With a `ChainReader`, the gate can look up how much a caller has paid to `pay_to` over a recent window. When that total is above `bulk_threshold`, the price is multiplied by `bulk_discount`.

```python
from ai_economy_sdk import ChainReader

gate = PaymentGate(
    signer=signer,
    network="localnet",
    pay_to=server_address,
    asset_id=0,
    prices={"heavy_task": 10000},
    chain=ChainReader("http://localhost:8980"),
    bulk_threshold=50_000,  # more than 50,000 microALGO paid ...
    bulk_days=30,           # ... in the last 30 days
    bulk_discount=0.5,      # gets 50% off
)
```

Bulk discounts need the caller's address, which comes from its identity proof. `ChainReader.for_network("testnet")` creates a reader for a public network's default indexer.

## Order of evaluation

For each tool call, `PaymentGate.price_for` does the following:

1. Take the base price from `prices` (dict or callable) or `default_price`.
2. If the base price is 0, the call is free.
3. If the caller holds a valid [pass](/ai-economy-sdk/passes) for one of `pass_scopes`, or a valid subscription token, the call is free.
4. If the caller's past spend is above `bulk_threshold`, apply `bulk_discount`.
5. For ALGO prices, apply the fee floor (below).

## The fee floor

For every settled call the server's fee payer pays 2,000 microALGO in fees (two transactions at the 1,000 microALGO minimum). An ALGO price at or below 2,000 microALGO loses money on every call, so the gate guards against it:

- A fixed price (`prices` dict or `default_price`) in `0 < price <= 2000` raises `ValueError` when the gate is created.
- A price that ends up in that range at call time (from a callable or after a discount) is raised to 2,001 microALGO, with a warning logged once per tool.
- `allow_loss=True` turns both checks off, for deliberate subsidies.
- The floor applies only when `asset_id=0`. USDC and other ASA prices are not compared with ALGO fees, although the server still pays the fees in ALGO.

```text
ValueError: price 1000 for tool 'summarize' does not cover facilitator fees (2000 microalgos); raise it or pass allow_loss=True
```

## Complete example

This example starts a server on port 9202 with a dictionary price (`compute`, 6,000 microALGO), a dynamic price (`echo`, 5,000 plus 100 per word) and a 50% bulk discount above 10,000 microALGO of past spend, then makes three calls.

{/* example: localnet/pricing.py */}

```python localnet/pricing.py expandable
"""Pricing strategies in ai-economy-sdk: fixed per-tool, dynamic arguments, and bulk discounts.

Starts an in-process FastMCP server on port 9202 and exercises three calls from a
buyer account:
1. Fixed price from a tool dictionary (compute = 6,000 microALGO).
2. Dynamic price computed from call arguments (echo = 5,000 base + 100 per word).
3. Bulk discount (50% off) automatically applied once past usage exceeds 10,000 microALGO.

How to run:
    python localnet/pricing.py

What it prints:
    Call 1 (compute - fixed dict price): charge = 6000 microALGO, result = 42
    Call 2 (echo - dynamic price 5 words): charge = 5500 microALGO, result = echo: one two three four five
    Call 3 (compute - bulk discount 50%): charge = 3000 microALGO, result = 84
"""
import asyncio
import socket
import sys
import threading
import time
from pathlib import Path
from typing import Any

sys.path.insert(0, str(Path(__file__).resolve().parent))

import uvicorn
from fastmcp import FastMCP
from ai_economy_sdk import DefaultAvmSigner, PaymentGate, paid_mcp_session
from ai_economy_sdk.chain import ChainReader
from _localnet import ALGOD, INDEXER_URL, new_funded_account

SERVER_PORT = 9202
SERVER_URL = f"http://127.0.0.1:{SERVER_PORT}/sse"

TOOL_PRICES = {"compute": 6000}


def get_price(tool: str, args: dict[str, Any], sender: str | None) -> int:
    """Determine price based on tool name, arguments, and sender address."""
    if tool in TOOL_PRICES:
        return TOOL_PRICES[tool]
    if tool == "echo":
        words = len(args.get("text", "").split())
        return 5000 + words * 100
    return 5000


def main() -> None:
    server_sk, server_addr = new_funded_account(algos=10)
    buyer_sk, buyer_addr = new_funded_account(algos=10)

    mcp = FastMCP("PricingServer")

    @mcp.tool()
    def compute(n: int) -> int:
        """Double the input number."""
        return n * 2

    @mcp.tool()
    def echo(text: str) -> str:
        """Echo text back to the caller."""
        return f"echo: {text}"

    gate = PaymentGate(
        signer=DefaultAvmSigner(server_sk, algod_client=ALGOD),
        network="localnet",
        pay_to=server_addr,
        asset_id=0,
        prices=get_price,
        chain=ChainReader(INDEXER_URL),
        bulk_threshold=10_000,
        bulk_discount=0.5,
    )

    app = gate.wrap(mcp)
    server = uvicorn.Server(uvicorn.Config(app, host="127.0.0.1", port=SERVER_PORT, log_level="warning"))
    server_thread = threading.Thread(target=server.run, daemon=True)
    server_thread.start()

    # Wait for server to bind port
    for _ in range(50):
        try:
            socket.create_connection(("127.0.0.1", SERVER_PORT), 0.2).close()
            break
        except OSError:
            time.sleep(0.1)

    async def execute_client_calls() -> None:
        # Call 1: compute (fixed price: 6,000 microALGO)
        b0 = ALGOD.account_info(buyer_addr)["amount"]
        async with paid_mcp_session(SERVER_URL, buyer_sk, "localnet") as session:
            res1 = await session.call_tool("compute", {"n": 21})
        b1 = ALGOD.account_info(buyer_addr)["amount"]
        charge1 = b0 - b1
        print(f"Call 1 (compute - fixed dict price): charge = {charge1} microALGO, result = {res1.content[0].text}")

        # Call 2: echo with 5 words (dynamic price: 5,000 + 500 = 5,500 microALGO)
        async with paid_mcp_session(SERVER_URL, buyer_sk, "localnet") as session:
            res2 = await session.call_tool("echo", {"text": "one two three four five"})
        b2 = ALGOD.account_info(buyer_addr)["amount"]
        charge2 = b1 - b2
        print(f"Call 2 (echo - dynamic price 5 words): charge = {charge2} microALGO, result = {res2.content[0].text}")

        # Allow indexer to index preceding payments so cumulative usage exceeds 10,000 microALGO
        time.sleep(1.0)

        # Call 3: compute with bulk discount (6,000 * 0.5 = 3,000 microALGO)
        async with paid_mcp_session(SERVER_URL, buyer_sk, "localnet") as session:
            res3 = await session.call_tool("compute", {"n": 42})
        b3 = ALGOD.account_info(buyer_addr)["amount"]
        charge3 = b2 - b3
        print(f"Call 3 (compute - bulk discount 50%): charge = {charge3} microALGO, result = {res3.content[0].text}")

    try:
        asyncio.run(execute_client_calls())
    finally:
        server.should_exit = True
        server_thread.join(timeout=5)


if __name__ == "__main__":
    main()
```
