---
title: "HTTPX and requests"
description: "HTTP clients that answer 402 challenges automatically: build the Algorand payment, sign it and retry."
---

The official `x402` package wraps `httpx` and `requests` so that a `402` response is paid and retried without extra code:

1. You send an ordinary request.
2. The client's transport sees `402`, decodes `PAYMENT-REQUIRED`, and asks the `x402Client` for a payment.
3. The Algorand scheme fetches suggested parameters from algod, builds the group and signs your transaction.
4. The request is retried with `PAYMENT-SIGNATURE`.
5. The server settles and returns `200` with the body.

## httpx (async)

```python
import os

from x402 import x402Client
from x402.http.clients.httpx import wrapHttpxWithPayment
from x402_algorand import PayerAvmSigner
from x402_algorand.exact import register_exact_avm_client

buyer_signer = PayerAvmSigner.from_mnemonic(os.environ["PAYER_MNEMONIC"])
x402_client = x402Client()
register_exact_avm_client(x402_client, buyer_signer, algod_url="http://localhost:4001", algod_token="a" * 64)

async with wrapHttpxWithPayment(x402_client) as client:
    response = await client.get("http://127.0.0.1:9211/weather")
```

`wrapHttpxWithPayment` returns an `httpx.AsyncClient` with an `x402AsyncTransport`. `x402HttpxClient(x402_client, ...)` is an `httpx.AsyncClient` subclass that does the same and accepts the usual httpx arguments; `paid_mcp_session` uses it.

### Complete example

The buyer pays the [FastAPI paywall](/x402-algorand/fastapi) on port 9211 and checks its balance.

{/* example: localnet/httpx_client.py */}

```python localnet/httpx_client.py
"""HTTPX client that pays x402 paywalls automatically on LocalNet.

Start fastapi_paywall.py (port 9211) or flask_paywall.py (9212) first, then:

    python localnet/httpx_client.py [--url http://127.0.0.1:9211/weather]
"""

import argparse
import asyncio
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent))

from x402 import x402Client
from x402.http.clients.httpx import wrapHttpxWithPayment
from x402_algorand import PayerAvmSigner
from x402_algorand.exact import register_exact_avm_client

from _localnet import ALGOD, ALGOD_TOKEN, ALGOD_URL, new_funded_account


async def main(url: str) -> None:
    sk, addr = new_funded_account(5)
    before = ALGOD.account_info(addr)["amount"]

    client = x402Client()  # default spend controls allow ALGO up to 1,000,000 microALGO
    register_exact_avm_client(
        client, PayerAvmSigner.from_private_key(sk), algod_url=ALGOD_URL, algod_token=ALGOD_TOKEN
    )
    async with wrapHttpxWithPayment(client) as http:
        response = await http.get(url, timeout=30.0)
    print(response.status_code, response.json())

    spent = before - ALGOD.account_info(addr)["amount"]
    assert response.status_code == 200 and spent == 10_000, (response.status_code, spent)
    print(f"Paid exactly {spent} microALGO.")


if __name__ == "__main__":
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--url", default="http://127.0.0.1:9211/weather")
    asyncio.run(main(parser.parse_args().url))
```

## requests (sync)

For synchronous code, use `x402ClientSync` and mount the payment adapter on a `requests.Session`:

```python
import os

import requests
from x402 import x402ClientSync
from x402.http.clients import wrapRequestsWithPayment
from x402_algorand import PayerAvmSigner
from x402_algorand.exact import register_exact_avm_client

buyer_signer = PayerAvmSigner.from_mnemonic(os.environ["PAYER_MNEMONIC"])
x402_client = x402ClientSync()
register_exact_avm_client(x402_client, buyer_signer, algod_url="http://localhost:4001", algod_token="a" * 64)

session = wrapRequestsWithPayment(requests.Session(), x402_client)
response = session.get("http://127.0.0.1:9211/weather")
```

<Note>
  `wrapRequestsWithPayment` comes from the official `x402` package and follows its documented usage. The examples repository exercises the httpx client; the requests variant is not part of its runs.
</Note>
