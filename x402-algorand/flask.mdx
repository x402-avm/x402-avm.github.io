---
title: "Flask"
description: "Protect Flask routes with the official x402 WSGI middleware and the Algorand scheme."
---

Flask is synchronous, so it uses the sync variants of the x402 classes: `x402FacilitatorSync` and `x402ResourceServerSync`, with `payment_middleware(app, routes, server)` from `x402.http.middleware.flask`. The middleware wraps `app.wsgi_app`.

1. A request without payment to a protected route gets `402` with `PAYMENT-REQUIRED`.
2. A request with a valid `PAYMENT-SIGNATURE` is verified and settled, and the route's response is returned with `PAYMENT-RESPONSE`.

## Example

This server protects `GET /weather` for 10,000 microALGO on LocalNet, port 9212.

{/* example: localnet/flask_paywall.py */}

```python localnet/flask_paywall.py expandable
"""Flask paywall: GET /weather costs 10,000 microALGO on LocalNet (port 9212).

Uses the synchronous x402 classes; the server is payee, fee payer and facilitator.

    python localnet/flask_paywall.py
"""

import logging
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent))

from flask import Flask, jsonify
from werkzeug.serving import run_simple
from x402 import x402FacilitatorSync, x402ResourceServerSync
from x402.http.middleware.flask import payment_middleware
from x402_algorand import ServerAvmSigner, caip2_from_genesis_hash
from x402_algorand.exact import register_exact_avm_facilitator, register_exact_avm_server

from _localnet import ALGOD, new_funded_account

network = caip2_from_genesis_hash(ALGOD.suggested_params().gh)
signer = ServerAvmSigner.from_private_key(new_funded_account()[0], ALGOD)

facilitator = x402FacilitatorSync()
register_exact_avm_facilitator(facilitator, signer, network)
server = x402ResourceServerSync(facilitator)
register_exact_avm_server(server)

routes = {"GET /weather": {"accepts": [{
    "scheme": "exact", "price": {"amount": "10000", "asset": "0"},
    "network": network, "pay_to": signer.address,
}]}}

app = Flask(__name__)
payment_middleware(app, routes, server)


@app.get("/weather")
def weather():
    return jsonify(city="Boston", temperature=68, network=network)


if __name__ == "__main__":
    print(f"Flask paywall on http://127.0.0.1:9212/weather, pay to {signer.address}")
    logging.getLogger("werkzeug").setLevel(logging.ERROR)  # quiet dev-server banner and access log
    run_simple("127.0.0.1", 9212, app)
```

<sub>Source: [examples/localnet/flask_paywall.py](https://github.com/x402-avm/examples/blob/main/localnet/flask_paywall.py)</sub>

{/* /example */}

```bash
pip install x402-algorand "x402[flask]"
python localnet/flask_paywall.py
```

It prints the endpoint and the address that receives payments (a new account on every run):

```text
Flask paywall on http://127.0.0.1:9212/weather, pay to <server address>
```

In a second terminal, pay for it with the HTTPX client:

```bash
python localnet/httpx_client.py --url http://127.0.0.1:9212/weather
```

```text
200 {'city': 'Boston', 'network': 'algorand:tg0cyjEz14FZK9BTpL2q0TOyFbc0McwY', 'temperature': 68}
Paid exactly 10000 microALGO.
```

The buyer's balance fell by exactly the price: the server's account paid the fees.
