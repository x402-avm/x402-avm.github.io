## CAIP-2 on Algorand

Under the [Algorand CAIP-2 profile](https://github.com/ChainAgnostic/namespaces/blob/main/algorand/caip2.md), a network id is `algorand:` followed by the first 32 characters of the URL-safe base64 encoding of the 32-byte genesis hash.

- MainNet: `algorand:wGHE2Pwdvd7S12BL5FaOP20EGYesN73k`
- TestNet: `algorand:SGO1GKSzyE7IEPItTxCByw9x8FmnrCDe`
- LocalNet: derived from its genesis block, different for every LocalNet

## Network utilities

All four are exported from `x402_algorand` and `x402_algorand.utils`.

### caip2_from_genesis_hash

Converts a genesis hash (base64 string or 32 raw bytes) to a CAIP-2 id.

```python
import base64
from x402_algorand.utils import caip2_from_genesis_hash

caip2_from_genesis_hash("wGHE2Pwdvd7S12BL5FaOP20EGYesN73ktiC1qzkkit8=")
# 'algorand:wGHE2Pwdvd7S12BL5FaOP20EGYesN73k'

caip2_from_genesis_hash(base64.b64decode("wGHE2Pwdvd7S12BL5FaOP20EGYesN73ktiC1qzkkit8="))
# same id
```

### register_network

Registers a custom network (its algod and indexer URLs and genesis data) and returns its id.

```python
from x402_algorand.utils import register_network

network_id = register_network(
    genesis_hash="mFgazF+2uRS1tMiL9dsj01hJGySEmPN28B/TjjvpVW0=",
    genesis_id="privatenet-v1",
    algod_url="http://node.internal:4001",
    indexer_url="http://node.internal:8980",
)
# 'algorand:mFgazF-2uRS1tMiL9dsj01hJGySEmPN2'
```

Without URLs, the network is registered with `http://localhost:4001` and `http://localhost:8980`.

### normalize_network

Turns x402 v1 network names and legacy 44-character ids into short CAIP-2 ids, and returns valid short ids unchanged. Any other input raises `NetworkError` (a `ValueError`).

```python
from x402_algorand.utils import normalize_network

normalize_network("algorand-mainnet")  # 'algorand:wGHE2Pwdvd7S12BL5FaOP20EGYesN73k'
normalize_network("algorand-testnet")  # 'algorand:SGO1GKSzyE7IEPItTxCByw9x8FmnrCDe'
normalize_network("algorand:SGO1GKSzyE7IEPItTxCByw9x8FmnrCDexi9/cOUJOiI=")
# 'algorand:SGO1GKSzyE7IEPItTxCByw9x8FmnrCDe'
```

<Note>
  `normalize_network` does not accept the short names `"mainnet"`, `"testnet"` or `"localnet"`. Those are understood by `ai_economy_sdk.resolve_network`, which also reads a LocalNet's id from algod.
</Note>

### get_genesis_hash

Returns the full base64 genesis hash of a registered network.

```python
from x402_algorand.utils import get_genesis_hash

get_genesis_hash("algorand:wGHE2Pwdvd7S12BL5FaOP20EGYesN73k")
# 'wGHE2Pwdvd7S12BL5FaOP20EGYesN73ktiC1qzkkit8='
```

More utilities, such as `get_network_config` and `network_from_genesis_hash`, are in the [reference](/reference/python/x402-algorand/index).

## Cross-network protection

Both sides check that a payment belongs to the requirement's network:

- **Client.** `create_payment_payload` compares the genesis hash of its algod's suggested parameters with the requirement's network. If they differ it raises `NetworkMismatchError` (a `ValueError`), for example: `NetworkMismatchError: algod is on algorand:tg0cyjEz14FZK9BTpL2q0TOyFbc0McwY but the payment is for algorand:SGO1GKSzyE7IEPItTxCByw9x8FmnrCDe`.
- **Facilitator.** `verify()` derives the CAIP-2 id from each transaction's genesis hash. If it differs from the requirement's network, verification fails with `invalid_exact_avm_payload_genesis_hash_mismatch`.
